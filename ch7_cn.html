第 7 章

HBT微波噪声建模与参数提取技术

随着模拟与数字通信对高速度和高信噪比（SNR）需求的不断增长，高频低噪声电路与系统正变得日益重要。低噪声设计是大多数射频接收机电路的关键问题之一。一个特别重要的应用是单片微波集成电路（MMIC），其中高精度、随偏置和温度变化的噪声模型对于设计的首次成功至关重要。为了对低噪声放大器（LNA）进行计算机辅助设计（CAD），必须完整地表征晶体管的噪声参数和散射参数。因此，准确的高频噪声建模对于缩短开发周期、开发LNA不可或缺。图7.1给出了HBT噪声建模流程的典型框图[1, 2]。

从图7.1可以看出，小信号等效电路模型是噪声等效电路模型的基础。本征噪声源包括散粒噪声、热噪声和低频噪声（1/f噪声）。寄生噪声源则是外部电阻产生的热噪声。一个完整的噪声模型既有助于理解HBT内部的噪声源，同时也可用于电路设计。

7.1 噪声等效电路模型

完整的HBT小信号与噪声等效电路模型如图7.2所示。该电路模型由著名的T型小信号等效电路和六个噪声源 \(\overline{e_{bx}^2}\)、\(\overline{e_{bi}^2}\)、\(\overline{e_c^2}\)、\(\overline{e_e^2}\)、\(\overline{i_b^2}\) 与 \(\overline{i_c^2}\) 组成[2, 3]。由于T型等效电路与双极晶体管共基Y参数的原始推导更为接近，文献中通常将其用于HBT的小信号建模。此外，与π型等效电路相比，它涉及的简化假设更少。本征等效电路如图7.2b所示，它展示了噪声源及其位置。其中两个噪声源描述pn结直流电流引起的散粒噪声，一个表示本征基极电阻的热噪声。与集电极电流相关的两个噪声源的噪声贡献由同一批电子产生：它们从发射极注入基区，穿越基区后到达集电极，因此这些噪声源之间的相关性由一个时间延迟给出。

\[\overline{i_b^2} = 2qI_{\mathrm{B}}\Delta f\](7.1)
\[\overline{i_c^2} = 2qI_{\mathrm{C}}\Delta f\](7.2)

两个相关的电流噪声源 \(\overline{i_b^2}\) 和 \(\overline{i_c^2}\) 代表HBT本征部分的内部噪声源。这两个噪声源由其在中心频率 f 处带宽 Δ f 内的均方值表征，可由以下表达式给出。\(\overline{i_b^2}\) 与 \(\overline{i_c^2}\) 之间的互相关可表示为

\[\overline{i_b^{*}i_c} = 2qI_{\mathrm{C}}\left(e^{-j\omega\tau}-1\right)\Delta f\](7.3)

四个噪声源 \(\overline{e_{bx}^2}\)、\(\overline{e_{bi}^2}\)、\(\overline{e_c^2}\) 和 \(\overline{e_e^2}\) 表示接入电阻 Rbx、Rbi、Rc 和 Re 的噪声特性，简单地由下式给出：

\[\overline{e_{bi}^2} = 4kTR_{bi}\Delta f\](7.4)
\[\overline{e_{bx}^2} = 4kTR_{bx}\Delta f\](7.5)
\[\overline{e_c^2} = 4kTR_c\Delta f\](7.6)
\[\overline{e_e^2} = 4kTR_e\Delta f\](7.7)

其中 q 为电子电荷，k 为玻尔兹曼常数，T 为绝对温度，Ri 为电阻值；τ 为渡越时间延迟，IB 和 IC 分别为基极和集电极直流电流。

图 7.2　HBT噪声等效电路模型：(a) 寄生部分；(b) 本征部分

在小信号与噪声等效电路模型中（如图7.3所示），Lb、Lc 和 Le 表示基极、集电极和发射极馈线的电感；Cpb、Cpc 和 Cpbc 表示焊盘电容；Rbx 和 Rbi 分别为外部和本征基极电阻；Rc 和 Re 为集电极和发射极电阻；Cex 为外部基极—集电极电容；Cbe 和 Cbc 分别为本征基极—发射极电容和基极—集电极电容。

7.2 噪声参数推导

噪声等效电路模型可以分为三部分：输入网络、输出网络和中间网络。输入网络仅包含基极寄生元件（焊盘电容 Cpb 和串联电感 Lb），是一个无噪声网络。输出网络由集电极寄生元件（焊盘电容 Cpc、串联电感 Lc 和串联电阻 Rc）组成。中间网络包括本征部分、外部电阻 Rbx 和 Re 以及发射极串联电感 Le。基于噪声相关矩阵技术[4]，四个未知噪声参数的提取可按如下步骤进行：

1. 计算不含 Rbi 和 Cex 的HBT本征部分（带有两个噪声源 \(\overline{i_b^2}\) 和 \(\overline{i_c^2}\) 的虚线框）的导纳噪声相关矩阵：

\[C_{Y11} = \frac{I_{\mathrm{B}}}{2V_{\mathrm{T}}}\](7.8)
\[C_{Y22} = \frac{I_{\mathrm{C}}}{2V_{\mathrm{T}}}\](7.9)
\[C_{Y21} = \frac{I_{\mathrm{C}}\left(e^{-j\omega\tau}-1\right)}{2V_{\mathrm{T}}}\](7.10)
\[C_{Y12} = \frac{I_{\mathrm{C}}\left(e^{j\omega\tau}-1\right)}{2V_{\mathrm{T}}}\](7.11)

2. 将导纳噪声相关矩阵变换为阻抗噪声相关矩阵，并加入本征电阻 Rbi：

\[C_Z = \begin{bmatrix} C_{Z11} + R_{bi} & C_{Z12} + R_{bi} \\ C_{Z21} + R_{bi} & C_{Z22} + R_{bi} \end{bmatrix}\](7.12)

3. 将阻抗噪声相关矩阵变换为导纳噪声相关矩阵，并加入外部电容 Cex。这样，本征部分的导纳噪声相关矩阵可由 CY11I 至 CY22I 给出：

\[C_{Y11}^{I} = \frac{C_{Y11} + R_{bi}\left|\left[(1-\alpha)Y_{\mathrm{BE}} + Y_{\mathrm{BC}}\right]\right|^2}{|A|^2}\](7.13)
\[C_{Y21}^{I} = \frac{\left(C_{Y21} + R_{bi}\left|Y_{\mathrm{BC}}Y_{\mathrm{BE}}\right|^2\right)\left(-D - \frac{1}{Y_{\mathrm{BE}}Y_{\mathrm{BC}}^{*}} + \frac{\alpha}{\left|Y_{\mathrm{BC}}\right|^2} - \frac{B}{Y_{\mathrm{BE}}^{*}} + \frac{C^{*}\left[Y_{\mathrm{BC}} + (1-\alpha)Y_{\mathrm{BE}}\right]^{*}}{\left(Y_{\mathrm{BC}}Y_{\mathrm{BE}}\right)^{*}}\right)}{|A|^2}\](7.14)
\[C_{Y12}^{I} = \left(C_{Y21}^{I}\right)^{*}\](7.15)
\[C_{Y22}^{I} = \frac{\left(C_{Y22} + R_{bi}\left|Y_{\mathrm{BC}}Y_{\mathrm{BE}}\right|^2\right)\left(D + B(R_{bi} + 2R_{\mathrm{be}}) - 2\mathrm{Re}\left[\left(\frac{1}{Y_{\mathrm{BE}}} - \frac{\alpha}{Y_{\mathrm{BC}}}\right)C\right]\right)}{|A|^2}\](7.16)

其中

\[A = 1 + R_{bi}\left[Y_{\mathrm{BC}} + (1-\alpha)Y_{\mathrm{BE}}\right]\]
\[B = C_{Y11}\left|\frac{\alpha}{Y_{\mathrm{BC}}}\right|^2 + C_{Y22}\left(\left|\frac{1}{Y_{\mathrm{BE}}}\right|^2 + \left|\frac{1-\alpha}{Y_{\mathrm{BC}}}\right|^2\right) + 2\mathrm{Re}\left\{C_{Y12}\left|\frac{\alpha}{Y_{\mathrm{BC}}}\right|^2 \frac{j\omega}{\alpha_{\mathrm{o}}}\left(\frac{1}{\omega_{\alpha}} + \tau\right)\right\}\]
\[C = \frac{\left(C_{Y11} + C_{Y22}\right)}{\left|Y_{\mathrm{BE}}\right|^2} + \frac{C_{Y22}(1-\alpha^{*}) + C_{Y12}}{Y_{\mathrm{BE}}Y_{\mathrm{BC}}^{*}}\]
\[D = \left|\frac{1}{Y_{\mathrm{BE}}} - \frac{\alpha}{Y_{\mathrm{BC}}}\right|^2\]

4. 通过简单地加入外部电阻 Rbx 和 Re，将导纳噪声相关矩阵变换为链噪声相关矩阵。这一表述形式非常适合四个噪声参数的计算。中间网络的链噪声相关矩阵可由 CA11M 至 CA22M 表示为

\[C_{A11}^{\mathrm{M}} = \frac{C_{Y22}^{I}}{\left|Y_{21}\right|^2} + R_{bx} + R_{\mathrm{e}}\](7.17)
\[C_{A12}^{\mathrm{M}} = \frac{Y_{11}^{*}C_{Y22}^{I} - Y_{21}^{*}C_{Y21}^{I}}{\left|Y_{21}\right|^2}\](7.18)
\[C_{A12}^{\mathrm{M}} = \left(C_{A21}^{\mathrm{M}}\right)^{*}\](7.19)
\[C_{A22}^{\mathrm{M}} = C_{Y11}^{I} + \frac{\left|Y_{11}\right|^2 C_{Y22}^{I}}{\left|Y_{21}\right|^2} - 2\mathrm{Re}\left(\frac{Y_{11}}{Y_{21}}C_{Y21}^{I}\right)\](7.20)

其中上标 M 表示中间网络，Y11、Y12、Y21 和 Y22 为扩展了 Rbi 和 Cex 的本征部分（虚线框）的Y参数：

\[Y_{11} = Y_{\mathrm{EX}} + \frac{Y_{\mathrm{BC}} + (1-\alpha)Y_{\mathrm{BE}}}{A}\](7.21)
\[Y_{21} = -Y_{\mathrm{EX}} + \frac{-Y_{\mathrm{BC}} + \alpha Y_{\mathrm{BE}}}{A}\](7.22)
\[Y_{12} = -Y_{\mathrm{EX}} + \frac{-Y_{\mathrm{BC}}}{A}\](7.23)
\[Y_{22} = Y_{\mathrm{EX}} + \frac{Y_{\mathrm{BC}}\left(1 + Y_{\mathrm{BE}}R_{bi}\right)}{A}\](7.24)

其中

\[Y_{\mathrm{BE}} = \frac{1}{R_{\mathrm{be}}} + j\omega C_{\mathrm{be}}, \quad Y_{\mathrm{BC}} = j\omega C_{\mathrm{bc}}, \quad Y_{\mathrm{EX}} = j\omega C_{\mathrm{ex}}\]

5. 计算输出网络的链噪声相关矩阵：

\[C_A^{O} = R_{\mathrm{c}}\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}\](7.25)

6. 计算中间网络与输出网络级联的链噪声相关矩阵：

\[C_A' = C_A^{\mathrm{M}} + A_{\mathrm{M}}C_A^{o}A_{\mathrm{M}}^{+}\](7.26)

AM 为中间网络与输出网络级联的链矩阵，加号表示厄米特共轭。

所得链噪声相关矩阵 CA′ 与噪声参数（不含输入网络）的表达式为

\[C_{A11}' = C_{A11}^{\mathrm{M}} + R_{\mathrm{c}}\left|E\right|^2\](7.27)
\[C_{A12}' = C_{A12}^{\mathrm{M}} + R_{\mathrm{c}}EF^{*}\](7.28)
\[C_{A21}' = C_{A21}^{\mathrm{M}} + R_{\mathrm{c}}E^{*}F\](7.29)
\[C_{A22}' = C_{A22}^{\mathrm{M}} + R_{\mathrm{c}}\left|F\right|^2\](7.30)

其中

\[E = \frac{\left[(1-\alpha)Y_{\mathrm{EX}} + Y_{\mathrm{BC}}\right]Y_{\mathrm{BE}}R_{bi} + \left[(R_{\mathrm{BX}} + R_{\mathrm{E}})Y_{\mathrm{BE}} + 1\right]\left(Y_{\mathrm{EX}} + Y_{\mathrm{BC}} + R_{bi}Y_{\mathrm{EX}}Y_{\mathrm{BC}}\right)}{\left[-\alpha + (1-\alpha)R_{bi}Y_{\mathrm{EX}}\right]Y_{\mathrm{BE}} + \left(R_{\mathrm{E}}Y_{\mathrm{BE}} + 1\right)\left(Y_{\mathrm{EX}} + Y_{\mathrm{BC}} + R_{bi}Y_{\mathrm{EX}}Y_{\mathrm{BC}}\right)}\]
\[F = \frac{Y_{\mathrm{BE}}\left(Y_{\mathrm{EX}} + Y_{\mathrm{BC}} + R_{bi}Y_{\mathrm{EX}}Y_{\mathrm{BC}}\right)}{\left[-\alpha + (1-\alpha)R_{bi}Y_{\mathrm{EX}}\right]Y_{\mathrm{BE}} + \left(R_{\mathrm{E}}Y_{\mathrm{BE}} + 1\right)\left(Y_{\mathrm{EX}} + Y_{\mathrm{BC}} + R_{bi}Y_{\mathrm{EX}}Y_{\mathrm{BC}}\right)}\]

不含输入网络（Cpb 和 Lb）的噪声等效电路模型四个噪声参数的表达式推导如下[5]：

\[R_{\mathrm{n}}' = C_{A11}'\](7.31)
\[G_{\mathrm{opt}}' = \sqrt{\frac{C_{A22}'}{C_{A11}'} - \left(\frac{\mathrm{Im}\left(C_{A12}'\right)}{C_{A11}'}\right)^2}\](7.32)
\[B_{\mathrm{opt}}' = \frac{\mathrm{Im}\left(C_{A12}'\right)}{C_{A11}'}\](7.33)
\[F_{\min}' = 1 + 2\left[\mathrm{Re}\left(C_{A12}'\right) + G_{\mathrm{opt}}'C_{A11}'\right]\](7.34)

将式 (7.17)–(7.20) 代入式 (7.31)–(7.34)，中间网络与输出网络级联的噪声参数变为

\[F_{\min}' = 1 + 2\left[\mathrm{Re}\left(\frac{C_{Y22}^{I}Y_{11}^{*}}{\left|Y_{21}\right|^2} - \frac{C_{Y21}^{I}}{Y_{21}} + R_{\mathrm{c}}EF^{*}\right)\right] + G_{\mathrm{opt}}'R_{\mathrm{n}}'\](7.35)
\[R_{\mathrm{n}}' = \frac{C_{Y22}^{I}}{\left|Y_{21}\right|^2} + R_{bx} + R_{\mathrm{e}} + R_{\mathrm{c}}\left|E\right|^2\](7.36)
\[G_{\mathrm{opt}}' = \sqrt{\frac{C_{Y11}^{I} + \frac{C_{Y22}^{I}\left|Y_{11}\right|^2}{\left|Y_{21}\right|^2} - 2\mathrm{Re}\left(\frac{Y_{11}C_{Y21}^{I}}{Y_{21}}\right) + R_{\mathrm{C}}\left|F\right|^2}{R_{\mathrm{n}}'} - \left|B_{\mathrm{opt}}'\right|^2}\](7.37)
\[B_{\mathrm{opt}}' = \frac{1}{R_{\mathrm{n}}'}\mathrm{Im}\left(\frac{C_{Y22}^{I}Y_{11}^{*}}{\left|Y_{21}\right|^2} - \frac{C_{Y21}^{I}}{Y_{21}} + R_{\mathrm{c}}EF^{*}\right)\](7.38)

7. 加入输入网络

由于 Fmin 对二端口输入和输出端口处的无损变换保持不变，RnGopt 对无损变换也保持不变[6]，因此 Yopt 可按下式计算：

\[Y_{\mathrm{opt}} = \frac{1}{\frac{1}{Y_{\mathrm{opt}}'} - j\omega L_{\mathrm{b}}} - j\omega C_{\mathrm{pb}}\](7.39)

借助前述噪声参数沿无损网络的变换，参考平面可以方便地移动到输入端口，从而将 Cpb 和 Lb 包含进来：

\[F_{\min} = F_{\min}'\](7.40)
\[G_{\mathrm{opt}} = \frac{G_{\mathrm{opt}}'}{\sqrt{1 + \omega^2 L_{\mathrm{b}}^2\left|Y_{\mathrm{opt}}'\right|^2 + 2\omega B_{\mathrm{opt}}'L_{\mathrm{b}}}}\](7.41)
\[B_{\mathrm{opt}} = \frac{B_{\mathrm{opt}}' + \omega L_{\mathrm{b}}\left|Y_{\mathrm{opt}}'\right|^2}{1 + \omega^2 L_{\mathrm{b}}^2\left|Y_{\mathrm{opt}}'\right|^2 + 2\omega B_{\mathrm{opt}}'L_{\mathrm{b}}} - \omega C_{\mathrm{pb}}\](7.42)
\[R_{\mathrm{n}} = \frac{R_{\mathrm{n}}'G_{\mathrm{opt}}'}{G_{\mathrm{opt}}}\](7.43)

在低频下，输入和输出网络的影响可以忽略，电流增益 α 接近 1，且噪声源之间的相关为零。因此，表达式 (7.40)–(7.43) 可简化为[4]

\[R_{\mathrm{n}} = \frac{R_{\mathrm{be}}^2 I_{\mathrm{C}}}{2V_{\mathrm{T}}} + R_{bi}\left[1 + (R_{bi} + 2R_{\mathrm{be}})\frac{I_{\mathrm{B}}}{2V_{\mathrm{T}}}\right] + R_{bx} + R_{\mathrm{e}}\](7.44)
\[B_{\mathrm{opt}} = -\omega\left(C_{\mathrm{ex}} + C_{\mathrm{bc}}\right)\](7.45)
\[G_{\mathrm{opt}} = \sqrt{\frac{I_{\mathrm{B}}}{2V_{\mathrm{T}}R_{\mathrm{n}}}}\](7.46)
\[F_{\min} = 1 + 2\left[\frac{R_{bi}I_{\mathrm{B}}}{2V_{\mathrm{T}}} + \sqrt{\frac{I_{\mathrm{B}}R_{\mathrm{n}}}{2V_{\mathrm{T}}}}\right]\](7.47)

可以看出，在低频范围内确定噪声参数时，只需要四个电阻（外部电阻 Rbx、Re 和本征电阻 Rbi、Rbe）以及两个基极—集电极电容之和 Cex+Cbc。当然，这一近似不包含 1/f 噪声。

为了验证所推导的四个噪声参数表达式，对 InP/InGaAs DHBT 进行了表征。器件结构和制作工艺的详情见文献 [6]。用于模型提取与验证的S参数测量采用 Agilent 8510C 矢量网络分析仪完成，频率最高达 40 GHz；直流偏置由 Agilent 4156A 提供。微波噪声参数测量采用 ATN 微波噪声测量系统（NMS）NP5，在片测量频率范围为 2–20 GHz。

确定半导体器件噪声参数的常用方法有两大类：基于调谐器的方法[7–11]和基于 50 Ω 噪声系数测量系统的方法[12]。

7.3.1 基于调谐器的提取方法

噪声参数的确定通常通过分析测量噪声系数随源阻抗的变化来完成，至少需要四次独立测量。然而，为了提高精度，通常进行四次以上的测量，然后使用曲线拟合技术确定噪声参数。图 7.10 给出了基于调谐器的噪声参数测量系统，典型的源反射系数 ΓS 分布史密斯圆图如图 7.11 所示。

图 7.10　基于调谐器的噪声参数测量系统
图 7.11　典型源反射系数分布史密斯圆图

从电路的角度看，HBT 器件可以视为一个有噪声二端口黑盒。众所周知，线性有噪声二端口网络的噪声特性可以由四个噪声参数 Fmin、Rn、Gopt 和 Bopt 表征为

\[F = F_{\min} + \frac{R_{\mathrm{n}}}{G_{\mathrm{s}}}\left[\left(G_{\mathrm{s}} - G_{\mathrm{opt}}\right)^2 + \left(B_{\mathrm{opt}} - B_{\mathrm{s}}\right)^2\right]\](7.48)

其中 F 为噪声系数，Ys=Gs+jBs 为源导纳，Fmin 为最小噪声系数，Rn 为噪声电阻，Yopt=Gopt+jBopt 为最佳源导纳。

噪声系数可以视为源导纳（Ys=Gs+jBs）的非线性函数[7]：

\[F = A + BG_{\mathrm{s}} + \frac{C + BB_{\mathrm{s}}^2 + DB_{\mathrm{s}}}{G_{\mathrm{s}}}\](7.49)

其中

\[A = F_{\min} - 2R_{\mathrm{n}}G_{\mathrm{opt}}, \quad B = R_{\mathrm{n}}, \quad C = R_{\mathrm{n}}\left(G_{\mathrm{opt}}^2 + B_{\mathrm{opt}}^2\right), \quad D = -2R_{\mathrm{n}}B_{\mathrm{opt}}\]

将 n 个观测噪声系数对式 (6.67) 的平面做最小二乘拟合，因此建立如下误差判据[8]：

\[\varepsilon = \frac{1}{2}\sum_{i=1}^{n}\left[A + B\left(G_{\mathrm{s}i} + \frac{B_{\mathrm{s}i}^2}{G_{\mathrm{s}i}}\right) + \frac{C}{G_{\mathrm{s}i}} + \frac{DB_{\mathrm{s}i}}{G_{\mathrm{s}i}} - F_{si}\right]^2\](7.50)

其中 Gsi 和 Bsi（i=1,2,…,n）为源电导和源电纳，Fi 为相应的噪声系数，Wi 为加权因子——当已知某些数据不如平均数据可靠时使用。

7.3.2 基于噪声系数测量的噪声参数确定

虽然基于调谐器的方法能得到准确结果，但耗时且需要昂贵的自动宽带微波调谐器，涉及复杂的校准过程。本节介绍一种在匹配源反射 50 Ω 测量系统（F50）基础上、无需自动调谐器确定 HBT 四个噪声参数的方法[12]。该方法基于噪声相关矩阵技术，通过拟合有源器件的测量噪声系数来确定四个噪声参数，具有以下优点：

  1. 用七个与频率无关的噪声参数表示本征部分的四个随频率变化的噪声参数。
  2. 七个与频率无关的噪声参数的初值由一组表达式计算得到，迭代计算非常快。
  3. 噪声参数的精度主要取决于噪声系数测量，而不仅仅取决于小信号模型参数和直流电流。因此可以消除来自小信号模型参数的误差。

这样的方法有利于验收测试，比使用源调谐器的完整测试更快，并且更可能在不使用调谐器的测试装置上完成。

7.3.2.1 噪声参数表达式

基于噪声相关矩阵技术，本征网络的噪声参数可以从等效电路模型推导得到。可以发现，四个噪声参数可以表示为频率的多项式函数。角频率 ω 的常数项和二次项主导 FminINT、GoptINT 和 RnINT，而 BoptINT 由线性项主导。本征网络的噪声参数可近似表示为

\[F_{\min}^{\mathrm{INT}} = K_A\left(1 + K_A'\omega^2\right)\](7.51)
\[G_{\mathrm{opt}}^{\mathrm{INT}} = K_B\left(1 + K_B'\omega^2\right)\](7.52)
\[B_{\mathrm{opt}}^{\mathrm{INT}} = K_C\omega\](7.53)
\[R_{\mathrm{n}}^{\mathrm{INT}} = K_D\left(1 + K_D'\omega^2\right)\](7.54)

其中 FminINT、GoptINT、BoptINT 和 RnINT 表示本征噪声参数；KA、KA′、KB、KB′、KC、KD 和 KD′ 为拟合因子；ω 为角频率。式 (7.51)–(7.54) 对带有寄生电阻 Rbx 和 Re 的本征器件同样有效，这两个电阻只影响拟合因子。这样，四个随频率变化的噪声参数变成了七个与频率无关的常数，因此可以直接从基于 50 Ω 的测量系统获得。拟合因子的初值可估计如下：

\[K_A = 1 + 2\left[\frac{R_{bi}I_{\mathrm{B}}}{2V_{\mathrm{T}}} + \sqrt{\frac{I_{\mathrm{B}}R_{\mathrm{n}}}{2V_{\mathrm{T}}}}\right]\](7.55)
\[K_B = \sqrt{\frac{I_{\mathrm{B}}}{2V_{\mathrm{T}}R_{\mathrm{n}}}}\](7.56)
\[K_C = C_{\mathrm{ex}} + C_{\mathrm{bc}}\](7.57)
\[K_D = \frac{R_{\mathrm{be}}^2 I_{\mathrm{C}}}{2V_{\mathrm{T}}} + R_{bi}\left[1 + (R_{bi} + 2R_{\mathrm{be}})\frac{I_{\mathrm{B}}}{2V_{\mathrm{T}}}\right] + R_{bx} + R_{\mathrm{e}}\](7.58)
\[K_A' \approx \frac{V_{\mathrm{T}}\left(R_{\mathrm{be}}C_{\mathrm{be}}\right)^2}{I_{\mathrm{B}}R_{bi}}\left(1 + \frac{K_D}{R_{bi}}\right) + \frac{K_D'}{2}\](7.59)
\[K_B' \approx \frac{2V_{\mathrm{T}}\left(R_{\mathrm{be}}C_{\mathrm{be}}\right)^2}{I_{\mathrm{B}}R_{bi}}\left(1 + \frac{K_D}{R_{bi}}\right) - K_D'\](7.60)
\[K_D' \approx -\frac{I_{\mathrm{C}}}{K_D V_{\mathrm{T}}}R_{bi}\left(R_{bi} + 2R_{\mathrm{be}}\right)\left(\frac{1}{\omega_{\alpha}} + \tau\right)\tau\](7.61)

在低频（典型地 f<3 GHz）下，FminINT、GoptINT 和等效噪声电阻 RnINT 与频率无关，而 BoptINT 与 ω 成正比[12]：

\[F_{\min}^{\mathrm{INT}} = K_A\](7.62)
\[G_{\mathrm{opt}}^{\mathrm{INT}} = K_B\](7.63)
\[B_{\mathrm{opt}}^{\mathrm{INT}} = K_C\omega\](7.64)
\[R_{\mathrm{n}}^{\mathrm{INT}} = K_D\](7.65)

因此，与频率无关的噪声参数 KA、KB、KC 和 KD 可以通过基于低频噪声系数测量的数值优化方法得到；然后 KA′、KB′ 和 KD′ 可以基于更高频率的噪声系数测量确定。值得注意的是，KC 可以从两种测量中提取。

7.3.2.2 噪声参数提取流程

一旦从S参数测量中提取出小信号元件，四个未知噪声参数的提取即可按如下流程进行：

  1. 测量 InP HBT 器件的S参数。
  2. 将S参数变换为导纳参数，并减去焊盘电容（Cpb、Cpc 和 Cpbc）。
  3. 将导纳参数变换为阻抗参数，并减去串联电感（Lb、Lc 和 Le）和串联电阻 Rc。
  4. 测量由输入偏置网络、输出偏置网络和有源器件组成的系统的噪声系数（Fm）。
  5. 测量输入和输出偏置网络的S参数。偏置网络包括同轴开关、偏置T、探针尖及其间的电缆（见图 7.13）。由于偏置网络的两个端口类型不同——一个为同轴端口、另一个为共面端口——很难直接用矢量网络分析仪（VNA）在片测量其S参数。因此，我们采用单端口测量方法确定偏置网络的S参数。

对二端口网络，输入反射系数可以表示为负载反射系数的函数：

\[S_{\mathrm{in}} = S_{11} + \frac{S_{12}S_{21}\Gamma_L}{1 - S_{22}\Gamma_L}\](7.66)

其中 Sin 为输入反射系数，ΓL 为负载反射系数。

首先，在 A-A 平面（输入端口）或 B-B 平面（输出端口）进行单端口同轴开路—短路—负载校准；然后，当探针尖分别连接到阻抗标准基片（ISS）上的开路、短路和负载标准件时测量S参数，对应 ΓL 等于 1、−1 和 0。偏置网络的S参数可以直接计算如下[13]：

\[S_{11} = S_{11}^{\mathrm{LOAD}}\](7.67)
\[S_{22} = \frac{S_{11}^{\mathrm{OPEN}} + S_{11}^{\mathrm{SHORT}} - 2S_{11}}{S_{11}^{\mathrm{OPEN}} - S_{11}^{\mathrm{SHORT}}}\](7.68)
\[S_{12} = S_{21} = \sqrt{\left(S_{11}^{\mathrm{OPEN}} - S_{11}\right)\left(1 - S_{22}\right)}\](7.69)

其中 S11OPEN、S11SHORT 和 S11LOAD 分别是探针尖接开路、短路和负载标准件时测得的输入反射系数。

图 7.13　输入与输出网络测量框图
  1. 计算被测器件（DUT）的噪声系数。

众所周知，有噪声二端口级联的噪声系数由下式给出：

\[F_{\mathrm{m}} = F_{\mathrm{IN}} + \frac{F_{\mathrm{D}} - 1}{G_{\mathrm{IN}}} + \frac{F_{\mathrm{OUT}} - 1}{G_{\mathrm{IN}}G_{\mathrm{D}}}\](7.70)

此时，FIN 和 GIN 为输入偏置网络的噪声系数和可用增益，FOUT 为输出偏置网络的噪声系数，FD 和 GD 为 DUT 的噪声系数和可用增益。

由于输入和输出偏置网络均为无源网络，可得

\[F_{\mathrm{IN}} = \frac{1}{G_{\mathrm{IN}}}, \quad F_{\mathrm{OUT}} = \frac{1}{G_{\mathrm{OUT}}}\](7.71)
\[F_{\mathrm{D}} = G_{\mathrm{IN}}F_{\mathrm{m}} - \frac{1 - G_{\mathrm{OUT}}}{G_{\mathrm{OUT}}G_{\mathrm{D}}}\](7.72)
  1. 设置四个噪声参数 KA、KB、KC 和 KD 的初值。计算本征部分的链噪声相关矩阵 CAD，由下式给出：
\[C_A^D = 4kT\begin{bmatrix} K_D & \frac{K_A - 1}{2} - K_D\left(K_B + j\omega K_C\right)^{*} \\ \frac{K_A - 1}{2} - K_D\left(K_B + j\omega K_C\right) & K_D\left(K_B^2 + \omega^2 K_C^2\right) \end{bmatrix}\](7.73)
  1. 将链噪声相关矩阵 CAD 变换为阻抗噪声相关矩阵，并加入串联电感（Lb、Lc 和 Le）和串联电阻 Rc。
  2. 将阻抗噪声相关矩阵变换为导纳噪声相关矩阵，并加入焊盘电容 Cpb、Cpc 和 Cpbc。
  3. 将导纳噪声相关矩阵变换为链噪声相关矩阵，噪声系数可表示如下：
\[F_{\mathrm{MODEL}} = 1 + 2\mathrm{Re}\left[C_{A12} + C_{A11}G_{\mathrm{opt}}\right] + \frac{C_{A11}}{G_{\mathrm{S}}}\left[\left(G_{\mathrm{S}} - G_{\mathrm{opt}}\right)^2 + \left(B_{\mathrm{S}} - B_{\mathrm{opt}}\right)^2\right]\](7.74)
  1. 以 DUT 的噪声系数为函数计算误差判据：
\[\varepsilon = \frac{1}{N-1}\sum_{i=0}^{N-1}\left[F_{\mathrm{MODEL}}\left(f_i\right) - F_{\mathrm{MEASURE}}\left(f_i\right)\right]^2\](7.75)

其中 N 为所考虑的频率点数，FMEASURE(fi) 为频率 fi 处的测量噪声系数，FMODEL(fi) 为由低频段提取的模型参数值计算得到的相应噪声系数。

  1. 若 ε>ε0，则使用最小二乘法更新 KA、KB、KC 和 KD 的值以减小 ε。
  2. 设置三个噪声参数 KA′、KB′ 和 KD′ 的初值。在得到因子 KA、KB、KC 和 KD 之后，KA′、KB′ 和 KD′ 可以方便地从更高频率的噪声系数测量中获得。它们的初值由下式给出：
\[K_A = \frac{F_{\min}^{c} - K_A}{K_A'\omega^2}\](7.76)
\[K_B = \frac{\left(G_{\mathrm{opt}}^{c} - K_B\right)^2}{K_B'\omega^2}\](7.77)
\[K_D = \frac{R_{\mathrm{n}}^{c} - K_D}{K_D'\omega^2}\](7.78)

其中 Fminc、Goptc、Boptc 和 Rnc 表示本征噪声参数。

  1. 利用步骤 10、11 和 12 确定噪声参数 KA′、KB′ 和 KD′。

7.4 共基、共射与共集组态

在放大器设计中，HBT 几乎都以共射（CE）组态工作。然而，共基（CB）组态具有易于实现宽带阻抗匹配、增益性能更好等优点，更适合光通信与微波宽带通信应用；同时，共集（CC）组态作为隔离器和缓冲器在 MMIC 中得到了广泛应用。为了对微波电路进行计算机辅助设计，必须完整地表征晶体管（CE、CB 和 CC）的噪声参数和散射参数。每种组态的S参数和噪声参数可以通过测量 CE、CB 和 CC 组态的测试图形获得，但这种方法需要为晶圆上的每种器件尺寸制作两个专门的测试结构（CB 和 CC），并且必须忽略晶圆上的非均匀性。另一种方案是给出 CE、CB 和 CC HBT 之间关系的解析表达式，这对理解不同组态之间的关系非常有吸引力且有用。本节介绍一种用于微波 HBT 器件的简单而高效的变换技术[14]。该技术基于等效电路模型与传统二端口网络信号/噪声相关矩阵技术的结合。利用一组简单的公式，可以从 CE 组态的信号和噪声参数直接获得 CB 和 CC 组态的信号和噪声参数。所有这些关系式分别为 CE、CB 和 CC HBT 之间的变换提供了双向桥梁。

链噪声相关矩阵更容易从噪声测量中获得，因为测量噪声参数（Fmin 为最小噪声系数、Rn 为噪声电阻、Gopt 为最佳源电导、Bopt 为最佳源电纳）与它之间有直接的关系。链噪声相关矩阵可以用四个噪声参数表示为

\[C_A^{Ci} = 4kT\begin{bmatrix} R_{\mathrm{n}}^{Ci} & \frac{F_{\min}^{Ci} - 1}{2} - R_{\mathrm{n}}^{Ci}\left(Y_{\mathrm{opt}}^{Ci}\right)^{*} \\ \frac{F_{\min}^{Ci} - 1}{2} - R_{\mathrm{n}}^{Ci}Y_{\mathrm{opt}}^{Ci} & R_{\mathrm{n}}^{Ci}\left|Y_{\mathrm{opt}}^{Ci}\right|^2 \end{bmatrix} \quad i = E, B, C\](7.88)

利用噪声源变换技术，CE、CB 和 CC 组态噪声等效电路模型中噪声源之间的关系可表示如下：

\[\upsilon_{\mathrm{CB}} = \frac{\upsilon_{\mathrm{CE}}}{A^{\mathrm{CE}} - 1}\](7.89)
\[i_{CB} = \frac{C^{CE}}{A^{CE} - 1}\upsilon_{CE} - i_{CE}\](7.90)
\[\upsilon_{\mathrm{CC}} = \upsilon_{\mathrm{CE}} + \frac{B^{\mathrm{CE}}}{1 - D^{\mathrm{CE}}}i_{\mathrm{CE}}\](7.91)
\[i_{\mathrm{CC}} = \frac{i_{\mathrm{CE}}}{1 - D^{\mathrm{CE}}}\](7.92)

图 7.25 给出了从 CE 组态出发、终于 CB 组态的一系列变换；图 7.26 给出了从 CE 组态出发、终于 CC 组态的一系列变换。图 7.25a 和 7.26a 中的电压和电流噪声源可以方便地变换为噪声电压源 υ1 和 υ2[15]：

\[\upsilon_1 = \upsilon_{\mathrm{CE}} - i_{\mathrm{CE}}Z_{11}^{\mathrm{CE}}\](7.93)
\[\upsilon_2 = -i_{\mathrm{CE}}Z_{21}^{\mathrm{CE}}\](7.94)

CE 与 CB 之间噪声参数的关系可表示如下：

\[R_{\mathrm{n}}^{\mathrm{CB}} = \frac{R_{\mathrm{n}}^{\mathrm{CE}}\left|Y_{21}^{\mathrm{CE}}\right|^2}{\left|Y_{21}^{\mathrm{CE}} + Y_{22}^{\mathrm{CE}}\right|^2}\](7.95)
\[B_{\mathrm{opt}}^{\mathrm{CB}} = \mathrm{Im}\left(\frac{\Delta Y^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right) + B_{\mathrm{opt}}^{\mathrm{CE}}\mathrm{Re}\left(\frac{Y_{22}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right) - \mathrm{Re}\left(k_3\right)\mathrm{Im}\left(\frac{Y_{22}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right)\](7.96)
\[G_{\mathrm{opt}}^{\mathrm{CB}} = \sqrt{\left|\frac{\Delta Y^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right|^2 + \left|Y_{\mathrm{opt}}^{\mathrm{CE}}\right|^2\left|\frac{Y_{22}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right|^2 - 2k_1 - \left(B_{\mathrm{opt}}^{\mathrm{CB}}\right)^2}\](7.97)
\[F_{\min}^{\mathrm{CB}} = 1 + 2\mathrm{Re}\left(G_{\mathrm{opt}}^{\mathrm{CB}}R_{\mathrm{n}}^{\mathrm{CB}} + k_2\right)\](7.98)

其中

\[k_1 = \mathrm{Re}\left[\frac{\Delta Y^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\left(\frac{Y_{22}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right)^{*} k_3\right]\]
\[k_2 = -R_{\mathrm{n}}^{\mathrm{CB}}\left(\frac{\Delta Y^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right)^{*} + \frac{k_3 R_{\mathrm{n}}^{\mathrm{CE}} Y_{21}^{\mathrm{CE}}}{Y_{22}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}\]
\[k_3 = \frac{F_{\min}^{\mathrm{CE}} - 1}{2R_{\mathrm{n}}^{\mathrm{CE}}} - \left(Y_{\mathrm{opt}}^{\mathrm{CE}}\right)^{*}, \quad \Delta Y^{\mathrm{CE}} = Y_{11}^{\mathrm{CE}}Y_{22}^{\mathrm{CE}} - Y_{12}^{\mathrm{CE}}Y_{21}^{\mathrm{CE}}\]

CE 与 CC 之间噪声参数的关系可表示如下：

\[R_{\mathrm{n}}^{\mathrm{CC}} = R_{\mathrm{n}}^{\mathrm{CE}}\left[1 + \left|\frac{1}{Y_{11}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}\right|^2\left|Y_{\mathrm{opt}}^{\mathrm{CS}}\right|^2\right] + 2k_4\](7.99)
\[B_{\mathrm{opt}}^{\mathrm{CC}} = \frac{\mathrm{Im}\left[k_3R_{\mathrm{n}}^{\mathrm{CE}}\left(\frac{Y_{21}^{\mathrm{CE}}}{Y_{11}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}\right)^{*}\right]}{R_{\mathrm{n}}^{\mathrm{CC}}} - \frac{R_{\mathrm{n}}^{\mathrm{CE}}\left|Y_{\mathrm{opt}}^{\mathrm{CE}}\right|^2\mathrm{Im}\left(\frac{1}{Y_{21}^{\mathrm{CE}}}\right)\left|Y_{21}^{\mathrm{CE}}\right|^2}{R_{\mathrm{n}}^{\mathrm{CC}}\left|Y_{11}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}\right|^2}\](7.100)
\[G_{\mathrm{opt}}^{\mathrm{CC}} = \sqrt{\frac{R_{\mathrm{n}}^{\mathrm{CE}}\left|Y_{\mathrm{opt}}^{\mathrm{CE}}\right|^2\left|Y_{21}^{\mathrm{CE}}\right|^2}{R_{\mathrm{n}}^{\mathrm{CC}}\left|Y_{21}^{\mathrm{CE}} + Y_{11}^{\mathrm{CE}}\right|^2} - \left(B_{\mathrm{opt}}^{\mathrm{CC}}\right)^2}\](7.101)
\[F_{\min}^{\mathrm{CC}} = 1 + 2\mathrm{Re}\left(G_{\mathrm{opt}}^{\mathrm{CC}}R_{\mathrm{n}}^{\mathrm{CC}} + k_5\right)\](7.102)

其中

\[k_4 = -\mathrm{Re}\left[\left(\frac{1}{Y_{11}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}\right)^{*} k_3 R_{\mathrm{n}}^{\mathrm{CE}}\right]\]
\[k_5 = \frac{k_3 R_{\mathrm{n}}^{\mathrm{CE}}}{\left(\frac{Y_{11}^{\mathrm{CE}} + Y_{21}^{\mathrm{CE}}}{Y_{21}^{\mathrm{CE}}}\right)^{*}} - \frac{\left|Y_{\mathrm{opt}}^{\mathrm{CE}}\right|^2\left(Y_{21}^{\mathrm{CE}}\right)^{*} R_{\mathrm{n}}^{\mathrm{CE}}}{\left|Y_{21}^{\mathrm{CE}} + Y_{11}^{\mathrm{CE}}\right|^2}\]

在 ω CgsRi≪1 的条件下（对 f<6 GHz 有效），通过忽略寄生元件的影响，本征 HBT 器件 CE、CB 和 CC 组态之间的噪声参数关系可以简化为

\[R_{\mathrm{n}}^{\mathrm{CB}} \approx R_{\mathrm{n}}^{\mathrm{CE}}\left(1 + \frac{\omega^2 R_{bi}C_{\mathrm{ex}}}{\omega_{\alpha}}\right)^2\](7.103)
\[F_{\min}^{\mathrm{CB}} \approx F_{\min}^{\mathrm{CE}}\](7.104)
\[B_{\mathrm{opt}}^{\mathrm{CB}} \approx -\frac{\omega^2 R_{bi}C_{\mathrm{ex}}/\omega_{\alpha}}{1 + \omega^2 R_{bi}C_{\mathrm{ex}}/\omega_{\alpha}}B_{\mathrm{opt}}^{\mathrm{CE}}\](7.105)
\[G_{\mathrm{opt}}^{\mathrm{CB}} \approx G_{\mathrm{opt}}^{\mathrm{CC}} \approx G_{\mathrm{opt}}^{\mathrm{CE}}\](7.106)
\[R_{\mathrm{n}}^{\mathrm{CC}} \approx R_{\mathrm{n}}^{\mathrm{CE}}\left(1 + R_{\mathrm{be}}^2\left|Y_{\mathrm{opt}}^{\mathrm{CE}}\right|\right)^2 - 2R_{\mathrm{be}}\left(\frac{F_{\min}^{\mathrm{CE}} - 1}{2} - G_{\mathrm{opt}}^{\mathrm{CE}}R_{\mathrm{n}}^{\mathrm{CE}}\right)\](7.107)
\[B_{\mathrm{opt}}^{\mathrm{CC}} \approx B_{\mathrm{opt}}^{\mathrm{CE}}\](7.108)
\[F_{\min}^{\mathrm{CC}} \approx F_{\min}^{\mathrm{CE}} - 2B_{\mathrm{opt}}^{\mathrm{CE}}R_{\mathrm{n}}^{\mathrm{CE}}\omega\left(\tau + \frac{1}{\omega_{\alpha}}\right)\](7.109)
