几乎每一个微波与射频（RF）有源和无源器件都可以视为一个二端口网络。二端口等效电路模型在电路设计中广泛用于描述有源和无源器件的电学行为。半导体器件建模的基本思想是：把复杂的有源器件表示为一个由基本电路元件——如电阻、电感、电容以及受控源——构成的二端口电路（参见图 2.1）。借助等效电路模型，电路设计者可以直观地理解复杂有源器件的工作机理。微波信号与噪声矩阵分析技术既是表示微波网络的基础，也是射频与微波半导体建模和参数提取的重要工具。本章将围绕二端口特性展开，重点讨论如何用一组能够写成矩阵形式的参数来描述器件。本章将：

  • 介绍重要的线性参数（包括信号参数与噪声参数）；
  • 讨论二端口网络的互联；
  • 推导基本电路元件的信号与噪声网络参数；
  • 分析寄生元件的去嵌入技术；
  • 介绍基本电路元件的参数提取方法。

2.1 信号参数

最常用的二端口网络参数有阻抗 Z、导纳 Y、混合 H、传输 ABCD 和散射 S 参数。其中阻抗 Z、导纳 Y、混合 H 和传输 ABCD 通常被称为低频信号参数，基于各端口的电压和电流。由于在较高频段开路与短路都难以实现（寄生电容的影响），这些参数过去只能在低频段测量。散射 S 参数通常被称为高频信号参数，基于加在网络上的行波。每一组参数都能完整地表征线性网络，并且都具有通用的矩阵形式。基于 Z、Y、H、ABCD 参数的二端口网络示意如图 2.2a 所示，可以看到网络共有四个端口变量：V₁、V₂、I₁、I₂，其中可任取两个作为激励变量，其余两个作为响应变量。图 2.2b 给出了带有端口入射波与反射波的网络示意图。

图 2.2 二端口网络框图：（a）低频参数；（b）高频参数

图中 aᵢ（i = 1, 2）是入射归一化功率波，bᵢ（i = 1, 2）是反射归一化功率波。因此 a₁ 是输入端口的入射波，b₁ 是输入端口的反射波；类似地，a₂ 和 b₂ 分别是输出端口的入射波和反射波。可见二端口网络共有四个端口变量：a₁、a₂、b₁、b₂。一般取两个入射波作为激励变量，另外两个作为响应变量。入射与反射归一化功率波可表示如下：

\[\displaystyle a_1 = \frac{V_1 + Z_0 I_1}{2\sqrt{Z_0}}\](2.1)
\[\displaystyle b_1 = \frac{V_1 - Z_0 I_1}{2\sqrt{Z_0}}\](2.2)
\[\displaystyle a_2 = \frac{V_2 + Z_0 I_2}{2\sqrt{Z_0}}\](2.3)
\[\displaystyle b_2 = \frac{V_2 - Z_0 I_2}{2\sqrt{Z_0}}\](2.4)

类似地，可以反求各端口的电压与电流：

\[\displaystyle V_1 = \sqrt{Z_0}\left(a_1+b_1\right)\](2.5)
\[\displaystyle I_1 = \frac{a_1-b_1}{\sqrt{Z_0}}\](2.6)
\[\displaystyle V_2 = \sqrt{Z_0}\left(a_2+b_2\right)\](2.7)
\[\displaystyle I_2 = \frac{a_2-b_2}{\sqrt{Z_0}}\](2.8)

其中 Zₒ 是网络输入端与输出端连接传输线的特性阻抗。

2.1.1 低频参数

2.1.1.1 阻抗参数

开路阻抗参数（即 Z 参数）用于表征二端口网络，其激励量为输入端口电压 V₁ 和输出端口电压 V₂；此时 I₁ 和 I₂ 是自变量，V₁ 和 V₂ 是因变量。网络的运算可用下面的矩阵表示：

\[\displaystyle \begin{bmatrix}V_1\\V_2\end{bmatrix} = \begin{bmatrix}Z_{11}&Z_{12}\\Z_{21}&Z_{22}\end{bmatrix}\begin{bmatrix}I_1\\I_2\end{bmatrix}\](2.9)

Z 参数的定义式与物理含义归纳如下：

\[\displaystyle Z_{11}=\left.\frac{V_1}{I_1}\right|_{I_2=0}\]输入阻抗（输出端口开路）
\[\displaystyle Z_{12}=\left.\frac{V_1}{I_2}\right|_{I_1=0}\]反向传输阻抗（输入端口开路）
\[\displaystyle Z_{21}=\left.\frac{V_2}{I_1}\right|_{I_2=0}\]正向传输阻抗（输出端口开路）
\[\displaystyle Z_{22}=\left.\frac{V_2}{I_2}\right|_{I_1=0}\]输出阻抗（输入端口开路）

归一化 Z 参数可表示为：

\[\displaystyle [z]=\frac{[Z]}{Z_0}\](2.10)

当第二端口接任意负载阻抗 ZL 时，输入阻抗 Zin 为：

\[\displaystyle Z_{\mathrm{in}}=\frac{V_1}{I_1}=Z_{11}-\frac{Z_{12}Z_{21}}{Z_{22}+Z_L}\](2.11)

类似地，当第一端口接任意源阻抗 ZS 时，输出阻抗 Zout 为：

\[\displaystyle Z_{\mathrm{out}}=\frac{V_2}{I_2}=Z_{22}-\frac{Z_{12}Z_{21}}{Z_{11}+Z_S}\](2.12)

2.1.1.2 导纳参数

现在来看短路 Y 参数——电压作为自变量，因此被称为短路导纳参数，用以描述另一端口短路时网络的输入、输出、正向与反向导纳。短路导纳参数（即 Y 参数）以输入端口电流 I₁ 与输出端口电流 I₂ 为激励量；此时 V₁ 和 V₂ 是自变量，网络的运算可用如下两式描述：

\[\displaystyle I_1=Y_{11}V_1+Y_{12}V_2\](2.13)
\[\displaystyle I_2=Y_{21}V_1+Y_{22}V_2\](2.14)

Y 参数的定义式与物理含义归纳如下：

\[\displaystyle Y_{11}=\left.\frac{I_1}{V_1}\right|_{V_2=0}\]输入导纳（输出端口短路）
\[\displaystyle Y_{12}=\left.\frac{I_1}{V_2}\right|_{V_1=0}\]反向传输导纳（输入端口短路）
\[\displaystyle Y_{21}=\left.\frac{I_2}{V_1}\right|_{V_2=0}\]正向传输导纳（输出端口短路）
\[\displaystyle Y_{22}=\left.\frac{I_2}{V_2}\right|_{V_1=0}\]输出导纳（输入端口短路）

归一化 Y 参数可表示为：

\[\displaystyle [y]=Z_0[Y]\](2.15)

其中 Yₒ = 1 / Zₒ 是特性导纳。

当第二端口接任意负载导纳 YL 时，输入导纳 Yin 为：

\[\displaystyle Y_{\mathrm{in}}=\frac{I_1}{V_1}=Y_{11}-\frac{Y_{12}Y_{21}}{Y_{22}+Y_L}\](2.16)

类似地，当第一端口接任意源导纳 YS 时，输出导纳 Yout 为：

\[\displaystyle Y_{\mathrm{out}}=\frac{I_2}{V_2}=Y_{22}-\frac{Y_{12}Y_{21}}{Y_{11}+Y_S}\](2.17)

2.1.1.3 混合参数

混合参数用于表征二端口网络，其激励量为输入端口电流 I₁ 和输出端口电压 V₂；此时 I₁ 和 V₂ 是自变量，V₁ 和 I₂ 是因变量。网络的运算可用如下两式描述：

\[\displaystyle V_1=H_{11}I_1+H_{12}V_2\](2.18)
\[\displaystyle I_2=H_{21}I_1+H_{22}V_2\](2.19)

H 参数的定义式与物理含义归纳如下：

\[\displaystyle H_{11}=\left.\frac{V_1}{I_1}\right|_{V_2=0}\]输入阻抗（输出端口短路）
\[\displaystyle H_{12}=\left.\frac{V_1}{V_2}\right|_{I_1=0}\]反向电压增益（输入端口开路）
\[\displaystyle H_{21}=\left.\frac{I_2}{I_1}\right|_{V_2=0}\]正向电流增益（输出端口短路）
\[\displaystyle H_{22}=\left.\frac{I_2}{V_2}\right|_{I_1=0}\]输出导纳（输入端口开路）

值得注意的是，输出端口短路条件下的正向电流增益 H₂₁ 是半导体器件（如 BJT 与 FET）的一项重要参数。可以直接从 |H₂₁| 随频率变化的曲线得到典型优值——截止频率 fT，其定义为 |H₂₁| 下降到 1 时所对应的频率（参见图 2.3）。因此 fT 又称单位增益带宽，用于描述晶体管能够正常工作的速度。

图 2.3 晶体管 |H₂₁| 随频率变化曲线

归一化 H 参数可表示为：

\[\displaystyle [h]=\begin{bmatrix}H_{11}/Z_0&H_{12}\\H_{21}&H_{22}Z_0\end{bmatrix}\](2.20)

2.1.1.4 传输参数

传输参数以输入端口的电压与电流作为激励量来表征二端口网络；此时 V₁ 和 I₁ 是自变量，V₂ 和 I₂ 是因变量。网络的运算可用下面的矩阵表示：

\[\displaystyle \begin{bmatrix}V_1\\I_1\end{bmatrix}=\begin{bmatrix}A&B\\C&D\end{bmatrix}\begin{bmatrix}V_2\\-I_2\end{bmatrix}\](2.21)

或

\[\displaystyle \begin{bmatrix}V_1\\I_1\end{bmatrix}=\begin{bmatrix}A&B\\C&D\end{bmatrix}\begin{bmatrix}V_2\\-I_2\end{bmatrix}\](2.22)

其中 [ABCD] 称为二端口网络的链式矩阵，又称 ABCD 参数。链式矩阵非常便于级联连接的运算：注意，输入电压与输出电压相对应，输入电流则与输出电流的负值相对应。这意味着对于级联连接，只要把各级矩阵直接相乘即可——上一级的输出参数恰是下一级的输入参数。ABCD 参数的定义式与物理含义归纳如下：

\[\displaystyle A=\left.\frac{V_1}{V_2}\right|_{I_2=0}\]反向电压增益（输出端口开路）
\[\displaystyle B=\left.\frac{V_1}{-I_2}\right|_{V_2=0}\]负反向传输阻抗（输入端口短路）
\[\displaystyle C=\left.\frac{I_1}{V_2}\right|_{I_2=0}\]反向传输导纳（输出端口开路）
\[\displaystyle D=\left.\frac{I_1}{-I_2}\right|_{V_2=0}\]负反向电流增益（输入端口短路）

当第二端口接任意负载阻抗 ZL 时，输入阻抗 Zin 为：

\[\displaystyle Z_{\mathrm{in}}=\frac{V_1}{I_1}=\frac{B+AZ_L}{D+CZ_L}\](2.23)

当第一端口接任意源阻抗 ZS 时，输出阻抗 Zout 为：

\[\displaystyle Z_{\mathrm{out}}=\frac{V_2}{I_2}=\frac{B+DZ_S}{A+CZ_S}\](2.24)

归一化 ABCD 参数可表示为：

\[\displaystyle [a]=\begin{bmatrix}A&B/Z_0\\C Z_0&D\end{bmatrix}\](2.25)

2.1.2 S 参数

Z、Y、H 和 ABCD 参数在较高频率下难以准确测量，因为所需的短路与开路测试在高频段难以实现。散射（S）参数是当前在数十 MHz 以上频段最容易测量的参数——它们是用 50 Ω 或 75 Ω 网络分析仪测得的。网络分析仪是大多数 RF 与微波电路设计所必需的基础基本工具，现代仪器可以通过一组基础校准实现快速、高精度的测量。S 参数在高频段用于表征 RF/微波二端口网络，基于参数基于行波概念，能够完整地刻画被分析或被测二端口网络在高频下的特性。S 参数以输入端口与输出端口的入射波作为激励量；此时 a₁ 和 a₂ 是自变量，b₁ 和 b₂ 是因变量。网络的运算可用下面的矩阵表示：

\[\displaystyle \begin{bmatrix}b_1\\b_2\end{bmatrix}=\begin{bmatrix}S_{11}&S_{12}\\S_{21}&S_{22}\end{bmatrix}\begin{bmatrix}a_1\\a_2\end{bmatrix}\](2.26)

S 参数的定义式与物理含义归纳如下：

\[\displaystyle S_{11}=\left.\frac{b_1}{a_1}\right|_{a_2=0}\]输入反射系数（输出端口接匹配负载）
\[\displaystyle S_{21}=\left.\frac{b_2}{a_1}\right|_{a_2=0}\]正向传输系数（输出端口接匹配负载）
\[\displaystyle S_{12}=\left.\frac{b_1}{a_2}\right|_{a_1=0}\]反向传输系数（输入端口接匹配负载）
\[\displaystyle S_{22}=\left.\frac{b_2}{a_2}\right|_{a_1=0}\]输出反射系数（输入端口接匹配负载）

下面讨论 S 参数与输入、输出端口电压之间的关系。图 2.4 给出了用于计算 S₁₁、S₂₁ 的框图。当输出端口接匹配负载（ZL = Zₒ，VS′ = 0）时，输入反射系数可表示为 [1]：

\[\displaystyle S_{11}=\frac{2V_1}{V_S}-1\](2.27)
\[\displaystyle S_{21}=\frac{2V_2}{V_S}\](2.28)
图 2.4 S 参数计算框图

当输入端口接匹配负载（ZS = Zₒ，VS = 0）时，输出反射系数可表示为：

\[\displaystyle S_{22}=\frac{2V_2}{V_S}-1\](2.29)
\[\displaystyle S_{12}=\frac{2V_1}{V_S}\](2.30)

由式 (2.27)–(2.31) 可见，S 参数可以直接由输入、输出节点电压与源电压求出。

值得一提的是，目前大多数射频仪器与同轴电缆采用 50 Ω 的标准阻抗。实际上，50 Ω 参考阻抗是在空气介质同轴线的最低损耗与最大功率容量之间折中选取的结果 [2, 3]。考虑以空气为介质的同轴电缆（参见图 2.5），其特性阻抗可表示为：

\[\displaystyle Z_0=\sqrt{\frac{\mu}{\varepsilon}}\frac{\ln(b/a)}{2\pi}\approx\frac{60}{\sqrt{\varepsilon_r}}\ln\frac{b}{a}\](2.31)

其中 a、b 分别为内、外导体半径；μ 和 ε 分别为磁导率与介电常数；εr 为相对介电常数（空气介质下 εr = 1）。

当外、内导体半径之比满足下式时，可获得最大功率容量：

\[\displaystyle \frac{b}{a}=\sqrt{e}=1.649\](2.32)

（原书印刷为 e = 1.649，意为 b/a = √e = 1.649；ln(b/a) = 0.5。）

图 2.5 空气介质同轴电缆的结构

将式 (2.32) 代入式 (2.31)，可得

\[\displaystyle Z_0^{p}\approx60\ln\frac{b}{a}=30\,\Omega\](2.33)

在以空气为介质的同轴结构中，使衰减最小所对应的最佳外、内导体半径之比为

\[\displaystyle \ln\frac{b}{a}=1+\frac{a}{b}\](2.34)

经迭代可解得 b/a 约为 3.6。

将式 (2.34) 代入式 (2.35)（原文如此；实为代入式 (2.31)），可得

\[\displaystyle Z_0^{a}\approx60\ln\frac{b}{a}=77\,\Omega\](2.35)

因此，射频系统的标准阻抗可由 77 Ω 与 30 Ω 的几何平均近似得到：

\[\displaystyle Z_0=\sqrt{Z_0^{p}Z_0^{a}}\approx50\,\Omega\](2.36)

由此可见，50 Ω 标准是同轴电缆最佳衰减性能与最大峰值功率容量之间的折中。

2.2 噪声二端口网络的表示

线性噪声网络的电路理论表明：任意含噪二端口都可以用一个噪声等效电路来代替，该等效电路由原二端口（此时假定为无噪）和两个额外的相关噪声源组成。本节将讨论三种最常用的噪声等效电路形式及其对应的相关矩阵——阻抗、导纳与链式噪声表示。

2.2.2 噪声参数

基于二端口网络的不同噪声表示，对应的噪声参数类型也不同。最常用的噪声参数类型有阻抗型、导纳型与反射系数型。通常，每种噪声参数类型包含四个噪声参数。

2.2.2.1 导纳型

当二端口网络由内导纳为 Ys 的信号源驱动时，噪声系数可写为

\[\displaystyle F=F_{\min}+\frac{R_n}{G_s}\left|Y_s-Y_{\mathrm{opt}}\right|^2\](2.52)

其中

\[\displaystyle Y_{\mathrm{opt}}=G_{\mathrm{opt}}+jB_{\mathrm{opt}}\]

2.2.2.2 阻抗型

当二端口网络由内阻抗为 Zs 的信号源驱动时，噪声系数可写为

\[\displaystyle F=F_{\min}+\frac{g_n}{R_s}\left|Z_s-Z_{\mathrm{opt}}\right|^2\](2.53)

其中

\[\displaystyle Z_{\mathrm{opt}}=R_{\mathrm{opt}}+jX_{\mathrm{opt}}\]

2.2.2.3 反射系数型

利用源反射系数的定义，式 (2.50) 与 (2.51)（原文如此；实为式 (2.52) 与 (2.53)）可改写为：

\[\displaystyle F=F_{\min}+N\frac{\left|G_s-G_{\mathrm{opt}}\right|^2}{\left(1-\left|G_s\right|^2\right)\left(1-\left|G_{\mathrm{opt}}\right|^2\right)}\](2.54)
\[\displaystyle F=F_{\min}+\frac{4R_n}{Z_0}\frac{\left|G_s-G_{\mathrm{opt}}\right|^2}{\left(1-\left|G_s\right|^2\right)\left|1+G_{\mathrm{opt}}\right|^2}\](2.55)

其中 Ys 为源导纳，Zs 为源阻抗，Γs 为源反射系数：

\[\displaystyle Y_s=G_s+jB_s\]
\[\displaystyle Z_s=R_s+jX_s\]

2.3 基本电路元件

组成有源半导体器件等效电路的元件称为基本电路元件。"基本"意味着这些电路元件已无法再分解为其它元件。因此基本电路构成了用以描述实际元器件行为的电路模型的最小构件，但它们自身不能用任何其它类型的元件来表示。基本电路元件共有四种：电阻、电感、电容以及受控源。本节将介绍这些基本电路元件的信号矩阵与噪声矩阵。

2.3.1 电阻

在半导体建模过程中，电阻通常用于表示有源器件的欧姆接触以及传输线的损耗。图 2.9 给出了单电阻 R 的串联与并联网络。

图 2.9 单电阻的（a）串联与（b）并联网络

\[[Y]_S = \frac{1}{R}\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}\](2.56)
\[[A]_S = \begin{bmatrix} 1 & R \\ 0 & 1 \end{bmatrix}\](2.57)
\[[S]_S = \frac{1}{R + 2Z_o}\begin{bmatrix} R & 2Z_o \\ 2Z_o & R \end{bmatrix}\](2.58)

其导纳表示下的相关噪声矩阵为：

电容定义为两电极间电场中存储能量的能力，或在两端存在电压差时结构存储电荷的能力。其大小取决于电极面积、电极间距以及极板间的介质材料。最常用的电容是用于半导体器件建模的 pn 结电容。在 pn 结的空间电荷区中，正负电荷彼此分离，因此 pn 结必然伴随一个电容。图 2.10 给出了单电容 C 的典型串联与并联网络。

对于单电容 C 的串联网络，其信号参数可表示为：

\[[Y]_S = j\omega C\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}\](2.64)
\[[A]_S = \begin{bmatrix} 1 & -\dfrac{j}{\omega C} \\ 0 & 1 \end{bmatrix}\](2.65)
\[[S]_S = \frac{1}{2Z_o + \dfrac{-j}{\omega C}}\begin{bmatrix} \dfrac{-j}{\omega C} & 2Z_o \\ 2Z_o & \dfrac{-j}{\omega C} \end{bmatrix}\](2.66)

对于单电容 C 的并联网络，其信号参数可表示为：

纯电容网络是无源无损二端口网络，因此其相关噪声矩阵为零。需要指出的是，电容网络对半导体器件的噪声贡献并不为零，器件的最佳源导纳会因并存的电容而改变。

2.3.5 理想传输线

射频与微波设计借鉴了用于低频段的模拟设计技术与用于高频段的高频设计技术（即微波理论）。低频模拟与微波设计之间最根本的区别是：微波设计中传输线的概念至关重要，而低频模拟设计则不然。众所周知，频率升高意味着波长减小。这对射频/微波电路带来的影响是：当与电路元件的几何尺寸相比时，电压与电流不再保持空间均匀。因此，低频电路理论与高频传输线理论之间的关键差异在于电尺寸：低频电路分析假定网络的物理尺寸远小于电波长，而传输线则可能是波长的可观分数倍甚至多个波长。因此，传输线一般不能用集总参数来描述，而应当是分布参数网络——其上的电压与电流的幅度与相位可以沿长度变化——尽管如此，基尔霍夫定律并不能直接应用；不过若把传输线细分成许多微小（无限小）的小段，在每一小段上电压与电流可以视为不变。

图 2.18 给出了理想传输线，其中 θ = βl 为电长度，β 为传播常数，l 为传输线的物理长度。其对应的链式参数与 S 参数可表示为：

\[[A] = \begin{bmatrix} \cos\theta & jZ_o\sin\theta \\ jY_o\sin\theta & \cos\theta \end{bmatrix}\](2.106)
图 2.18 理想传输线
\[[S] = \begin{bmatrix} 0 & e^{-j\theta} \\ e^{-j\theta} & 0 \end{bmatrix}\](2.107)

当一段无耗传输线终端接任意负载阻抗 ZL、距负载为 l 处的输入阻抗与导纳分别为：

\[Z_{\mathrm{in}} = Z_o\,\frac{Z_L + jZ_o\tan\theta}{Z_o + jZ_L\tan\theta}\](2.108)
\[Y_{\mathrm{in}} = Y_o\,\frac{Y_L + jY_o\tan\theta}{Y_o + jY_L\tan\theta}\](2.109)

其对应的输入反射系数为：

\[\Gamma_{\mathrm{in}} = \frac{Z_{\mathrm{in}} - Z_o}{Z_{\mathrm{in}} + Z_o} = \frac{Y_o - Y_{\mathrm{in}}}{Y_o + Y_{\mathrm{in}}}\](2.110)

由式 (2.110) 可见，当传输线无耗且终端负载 ZL = Zo 时无反射 Γin = 0，且无论传输线长度如何输入阻抗始终等于 Zo。否则，若 ZL ≠ Zo，则存在反射，输入阻抗不再等于 Zo。

当传输线终端短路（ZL = 0）时，其输入阻抗、导纳与反射系数为：

\[Z_{\mathrm{in}} = jZ_o\tan\theta,\quad Y_{\mathrm{in}} = -jY_o\cot\theta,\quad \Gamma_{\mathrm{in}} = -e^{-2j\theta}\](2.111)

值得指出的是，集总电感可以视为一小段短路传输线（通常 l 小于十分之一波长）；其电感量可表示为

\[L = \frac{Z_o\,l}{\lambda f}\](2.112)

当传输线终端开路（ZL = ∞）时，其输入阻抗、导纳与反射系数为：

\[Z_{\mathrm{in}} = -jZ_o\cot\theta,\quad Y_{\mathrm{in}} = jY_o\tan\theta,\quad \Gamma_{\mathrm{in}} = e^{-2j\theta}\](2.113)

集总电容可视为一小段开路传输线（通常 l 小于十分之一波长）；其电容量可表示为

\[C = \frac{l}{\lambda f Z_o}\](2.114)

理想传输线在射频/微波测量中常用于参考面的平移。考虑图 2.19 所示的二端口网络：被测器件（DUT）通过两段相同的传输线分别连到端口 1 与端口 2。该系统的 S 参数可由矢量网络分析仪（VNA）直接测得——测量参考面假定位于 z = l 处，而 DUT 参考面位于 z = 0 处，其中 z 是沿传输线测量的任意坐标。下面说明当参考面从 z = 0 移到 z = l 时，S 参数如何变换。

根据 z = 0 处 S 参数的定义，有

\[b_1(0) = S_{11}\cdot a_1(0) + S_{12}\cdot a_2(0)\](2.115)
\[b_2(0) = S_{21}\cdot a_1(0) + S_{22}\cdot a_2(0)\](2.116)

由无耗传输线上的行波理论，有

\[a_j(l) = a_j(0)\,e^{-j\theta}\quad j = 1, 2\](2.117)
\[b_j(l) = b_j(0)\,e^{j\theta}\quad j = 1, 2\](2.118)
图 2.19 二端口网络参考面的平移

将式 (2.117) 和 (2.118) 代入式 (2.115) 和 (2.116)，得

\[\begin{bmatrix} b_1(l) \\ b_2(l) \end{bmatrix} = \begin{bmatrix} e^{j\theta} & 0 \\ 0 & e^{j\theta} \end{bmatrix}\begin{bmatrix} S_{11} & S_{12} \\ S_{21} & S_{22} \end{bmatrix}\begin{bmatrix} e^{j\theta} & 0 \\ 0 & e^{j\theta} \end{bmatrix}\begin{bmatrix} a_1(l) \\ a_2(l) \end{bmatrix}\](2.119)

这清楚地表明平移后网络的 S 参数由三个矩阵构成：

\[\begin{bmatrix} S_{11}^D & S_{12}^D \\ S_{21}^D & S_{22}^D \end{bmatrix} = \begin{bmatrix} S_{11}\,e^{j2\theta} & S_{12}\,e^{j2\theta} \\ S_{21}\,e^{j2\theta} & S_{22}\,e^{j2\theta} \end{bmatrix}\](2.120)

这一形式的物理意义非常直观。注意 SDii = Sii ej2θ（i = 1, 2），即 Sii 的相位被平移了传输线电长度 (2θ) 的两倍——这是因为入射与反射两次经过这段长度所造成的。同样，交叉项 S12 与 S21 的相位也偏移 2θ，原因是整个输入/输出结构都包含了这两段传输线。

2.4 π 型与 T 型网络

π 型与 T 型网络是电路分析中最常用的二端口网络，因为它们都能极大地简化复杂网络的分析。多数半导体器件的参数提取方法都建立在 π 型与 T 型网络的相互关系之上。

2.4.1 T 型网络

典型 T 型网络的示意图如图 2.20 所示；其对应的 Z 参数可写为：

\[Z_{11} = Z_A + Z_B\](2.121)
\[Z_{12} = Z_{21} = Z_B\](2.122)
\[Z_{22} = Z_B + Z_C\](2.123)
图 2.20 T 型网络作为二端口网络

其对应的 Y、ABCD 与 S 参数可表示如下：

\[\begin{bmatrix} Y \end{bmatrix} = \frac{1}{Z_A Z_B + Z_B Z_C + Z_A Z_C}\begin{bmatrix} Z_B + Z_C & -Z_B \\ -Z_B & Z_A + Z_B \end{bmatrix}\](2.124)
\[\begin{bmatrix} ABCD \end{bmatrix} = \begin{bmatrix} 1 + \dfrac{Z_A}{Z_B} & Z_C + Z_A\!\left(\dfrac{Z_C}{Z_B} + 1\right) \\ \dfrac{1}{Z_B} & 1 + \dfrac{Z_C}{Z_B} \end{bmatrix}\](2.125)

其中（公共中间量）

\[T = Z_A Z_B + Z_A Z_C + Z_B Z_C\]
\[\begin{bmatrix} S \end{bmatrix} = \frac{1}{Z_o^{2} + (Z_A + Z_C + 2Z_B)Z_o + T}\begin{bmatrix}-Z_o^{2} + (Z_A - Z_C)Z_o + T & 2Z_o Z_B \\2Z_o Z_B & -Z_o^{2} - (Z_A - Z_C)Z_o + T\end{bmatrix}\](2.126)

对于无源 T 型网络，阻抗噪声相关矩阵为：

\[C_Z = 4kT\,\mathrm{Re}\begin{bmatrix} Z_A + Z_B & Z_B \\ Z_B & Z_B + Z_C \end{bmatrix}= 4kT\begin{bmatrix} R_A + R_B & R_B \\ R_B & R_B + R_C \end{bmatrix}\](2.127)

其中 RA、RB、RC 分别为 ZA、ZB、ZC 的实部。

相应的导纳噪声相关矩阵为：

\[C_Y = \frac{4kT}{|N|^{2}}\begin{bmatrix} D & R_B \\ R_B & D \end{bmatrix}\](2.128)

其中

\[D = |Z_C|^{2}(R_A + R_B) + |Z_B|^{2}(R_A + R_C) + \mathrm{Re}\{Z_A Z_B Z_C^{*}\} + \mathrm{Re}\{Z_A Z_C Z_B^{*}\}\]
\[N = Z_A Z_B + Z_A Z_C + Z_B Z_C\]

2.4.2 π 型网络

典型 π 型网络（其名称源于该网络与希腊字母 π 的形状相似）的示意图如图 2.21 所示；其对应的 Y 参数可写为：

\[Y_{11} = \frac{1}{Z_1} + \frac{1}{Z_2}\](2.129)
\[Y_{12} = Y_{21} = -\frac{1}{Z_2}\](2.130)
\[Y_{22} = \frac{1}{Z_3} + \frac{1}{Z_2}\](2.131)
图 2.21 π 型网络作为二端口网络

其对应的 Z、ABCD 与 S 参数可表示如下：

\[\begin{bmatrix} Z \end{bmatrix} = \frac{1}{Z_1 + Z_2 + Z_3}\begin{bmatrix} Z_1(Z_2 + Z_3) & Z_1 Z_3 \\ Z_1 Z_3 & Z_3(Z_1 + Z_2) \end{bmatrix}\](2.132)
\[\begin{bmatrix} ABCD \end{bmatrix} = \begin{bmatrix} 1 + \dfrac{Z_2}{Z_3} & Z_2 \\ \dfrac{1}{Z_1}\!\left(1 + \dfrac{Z_2}{Z_3}\right) + \dfrac{1}{Z_3} & 1 + \dfrac{Z_2}{Z_1} \end{bmatrix}\](2.133)

其中（公共中间量）

\[T = Y_1 Y_2 + Y_1 Y_3 + Y_2 Y_3\]
\[Y_1 = \frac{1}{Z_1}\]
\[Y_2 = \frac{1}{Z_2}\]
\[Y_3 = \frac{1}{Z_3}\]
\[\begin{bmatrix} S \end{bmatrix} = \frac{1}{Y_o^{2} + (Y_1 + Y_3 + 2Y_2)Y_o + T}\begin{bmatrix}Y_o^{2} - (Y_1 - Y_3)Y_o - T & 2Y_o Y_2 \\2Y_o Y_2 & Y_o^{2} + (Y_1 - Y_3)Y_o - T\end{bmatrix}\](2.134)

对于无源 π 型网络，导纳噪声相关矩阵为：

\[C_Y = 4kT\,\mathrm{Re}\begin{bmatrix} Y_1 + Y_2 & -Y_2 \\ -Y_2 & Y_2 + Y_3 \end{bmatrix}= 4kT\begin{bmatrix} G_1 + G_2 & -G_2 \\ -G_2 & G_2 + G_3 \end{bmatrix}\](2.135)

其中 G1、G2、G3 分别为导纳 Y1、Y2、Y3 的实部。

2.4.3 π 型与 T 型网络的相互关系

π 型网络的每个元件都可以通过相应的定义式转换为 T 型网络。π 型与 T 型网络的相互转换关系可表示为：

\[Z_A = \frac{Z_1 Z_2}{Z_1 + Z_2 + Z_3}\](2.136)
\[Z_B = \frac{Z_1 Z_3}{Z_1 + Z_2 + Z_3}\](2.137)
\[Z_C = \frac{Z_2 Z_3}{Z_1 + Z_2 + Z_3}\](2.138)
\[Z_1 = \frac{Z_A Z_B + Z_B Z_C + Z_A Z_C}{Z_C}\](2.139)
\[Z_2 = \frac{Z_A Z_B + Z_B Z_C + Z_A Z_C}{Z_B}\](2.140)
\[Z_3 = \frac{Z_A Z_B + Z_B Z_C + Z_A Z_C}{Z_A}\](2.141)

上述关系为 π 型与 T 型网络的相互转换提供了一座双向桥梁，是化简复杂电路网络的强有力手段。化简技术让我们能把更复杂的结构只用欧姆定律结合基尔霍夫定律来分析。因此，从化简后的电路网络可得到一组简洁的信号参数表达式，对半导体器件模型参数的确定非常有价值。

考虑一个复杂的 π 型结构（如图 2.22a 所示），它由一个 T 型网络（图 2.22a 中虚线框内）与三个与之并联的元件组成。由于节点数超过两个，Y 参数无法直接由节点电压法写出。图 2.22 给出了更详细的化简过程：第一步是把 T 型网络（图 2.22a 中虚线框）转换为 π 型网络（图 2.22b 中虚线框），然后通过串-并联组合进一步化简所得电路。化简后的 π 型网络（图 2.22c）所对应的 Y 参数可表示如下：

图 2.22 复杂 π 型网络的化简过程：（a）复杂 π 型结构；（b）T 型网络向 π 型网络的转换；（c）化简后的 π 型网络
\[Y_{11} = \frac{1}{Z_1^{\prime}} + \frac{1}{Z_2^{\prime}}= \frac{1}{Z_1} + \frac{1}{Z_D} + \frac{1}{Z_2} + \frac{1}{Z_E}\](2.142)
\[Y_{12} = Y_{21} = -\frac{1}{Z_2^{\prime}}= -\!\left(\frac{1}{Z_2} + \frac{1}{Z_E}\right)\](2.143)
\[Y_{22} = \frac{1}{Z_3^{\prime}} + \frac{1}{Z_2^{\prime}}= \frac{1}{Z_3} + \frac{1}{Z_F} + \frac{1}{Z_2} + \frac{1}{Z_E}\](2.144)

\[Z_{11} = Z_A^{\prime} + Z_B^{\prime} = Z_A + Z_B + Z_5 + Z_6\](2.145)

2.5 去嵌入方法

众所周知，直接把共面探针放在器件上进行测量是不可能的。实际上，测量必须经由探针压焊点（pad）与互连走线才能到达 DUT。缺点是压焊点与互连引入的寄生效应可能比被测器件本身还大。去嵌入（deembedding）的目的就是去除由压焊点图形与馈线（或键合线）带来的寄生效应——去嵌入本质上就是二端口网络互联的逆运算。类似地，去嵌入技术有三种应用方式：并联、串联与级联去嵌入。详细过程将在下面逐一讨论。

2.5.1 并联去嵌入

图 2.24 给出了与 DUT 并联的三个寄生元件。为得到 DUT 自身的响应，并联去嵌入可以按如下步骤进行：

  1. 测量含寄生元件器件的 S 参数；
  2. 把 S 参数转换为 Y 参数；
  3. 减去并联寄生元件：
\[Y_{11}^{\mathrm{DUT}} = Y_{11}^{\mathrm{M}} - Y_{11}^{\mathrm{P}}\](2.148)
\[Y_{12}^{\mathrm{DUT}} = Y_{12}^{\mathrm{M}} - Y_{12}^{\mathrm{P}}\](2.149)
\[Y_{21}^{\mathrm{DUT}} = Y_{21}^{\mathrm{M}} - Y_{21}^{\mathrm{P}}\](2.150)
\[Y_{22}^{\mathrm{DUT}} = Y_{22}^{\mathrm{M}} - Y_{22}^{\mathrm{P}}\](2.151)

其中

\[Y_{11}^{\mathrm{P}} = Y_1 + Y_3\](2.152)
\[Y_{12}^{\mathrm{P}} = -Y_3\](2.153)
\[Y_{21}^{\mathrm{P}} = -Y_3\](2.154)
\[Y_{22}^{\mathrm{P}} = Y_2 + Y_3\](2.155)

上标 M 表示测量数据，P 表示寄生元件，DUT 表示被测器件。

4. 把 Y 参数转换回 S 参数。

图 2.24 与 DUT 并联的寄生元件

2.5.2 串联去嵌入

串联去嵌入技术是指去除与 DUT 串联的寄生效应，例如探针压焊点与探针针尖之间的接触电阻、互连线的串联损耗等。图 2.26 给出了与 DUT 串联的三个寄生元件。为得到 DUT 自身的响应，串联去嵌入可以按如下步骤进行：

  1. 测量含寄生元件器件的 S 参数；
  2. 把 S 参数转换为 Z 参数；
  3. 减去串联寄生元件：
\[Z_{11}^{\mathrm{DUT}} = Z_{11}^{\mathrm{M}} - Z_{11}^{\mathrm{S}}\](2.156)
\[Z_{12}^{\mathrm{DUT}} = Z_{12}^{\mathrm{M}} - Z_{12}^{\mathrm{S}}\](2.157)
\[Z_{21}^{\mathrm{DUT}} = Z_{21}^{\mathrm{M}} - Z_{21}^{\mathrm{S}}\](2.158)
\[Z_{22}^{\mathrm{DUT}} = Z_{22}^{\mathrm{M}} - Z_{22}^{\mathrm{S}}\](2.159)

其中串联网络的 Z 参数可表示如下：

\[Z_{11}^{\mathrm{S}} = Z_1 + Z_3\](2.160)
\[Z_{12}^{\mathrm{S}} = Z_3\](2.161)
\[Z_{21}^{\mathrm{S}} = Z_3\](2.162)
\[Z_{22}^{\mathrm{S}} = Z_2 + Z_3\](2.163)

上标 M 表示测量数据，S 表示串联网络，DUT 表示被测器件。

图 2.26 与 DUT 串联的寄生元件

同样，负元件法也可用于串联去嵌入，如图 2.27 所示：在寄生元件相同的位置，通过给原网络再串联三个取负值的元件，即可消除寄生元件的影响。

2.6 参数提取的基本方法

众所周知，电路模型的精度取决于相应的参数提取技术。若提取出的模型参数与真实值偏差较大，该模型就无法用于电路设计。因此，模型参数的确定应符合物理意义。本节将分别介绍电阻、电容与电感的基本参数提取技术。

2.6.1 电容的确定

微波集成电路中常见元件之一是叉指电容（interdigital capacitor），它是微带工艺中构建几皮法级电容的常用元件。图 2.29a 给出了平面微带叉指电容，它由形成在半导体层顶面的一对叉指电极构成。叉指电极、连接图形与压焊点可视为两块分离的极板。当单片叉指电容的最大尺寸小于工作频率下介质薄膜中波长的 1/10 时，该电容可以用一个等效电路表示，如图 2.29b 所示。去除压焊点电容 CP 后，叉指电容 C 可由本征部分的 Z 参数求得：

图 2.29 单片叉指电容：（a）版图；（b）等效电路模型
\[C = -\frac{1}{\omega\,\mathrm{Im}(Z)}\](2.165)

其中

\[Z = R_s + \frac{1}{j\omega C}\]

图 2.30 给出了典型的提取电容随频率的变化曲线。可以看到，电容可以在低频段确定，其幅度变化非常小、几乎可以忽略。随着频率升高，寄生元件（如外征电阻与电感）的影响越来越大，幅度的变化便不可忽略。

图 2.30 提取电容随频率的变化

2.6.2 电感的确定

利用当今主流 GaAs 工艺常规提供的多层互连，可以在 GaAs 衬底上制作螺旋电感。构建基本螺旋线圈以及把线圈内端引出到外部的下穿接触，至少需要两层金属。电感的横向结构由匝数、线宽与线间距（W 与 S）以及覆盖总面积决定。一个简单的集总元件模型足以描述器件的电学特性（图 2.31）。螺旋线圈本身用理想电感 L 与串联电阻 Rs 建模，Rs 表示线圈中的欧姆损耗。

去除压焊点电容 CP 后，螺旋电感 L 可由本征部分的 Z 参数求得：

图 2.31 单片螺旋电感：（a）版图；（b）等效电路模型
\[L = \frac{\mathrm{Im}(Z)}{\omega}\](2.166)

其中

\[Z = R_s + j\omega L\]

图 2.32 给出了典型的提取电感随频率的变化曲线。可以看到，电感可以在高频段确定，其幅度变化非常小、几乎可以忽略。低频时电感的阻抗非常小，难以与寄生元件区分。随着频率升高，电感的作用越来越大，并在高频段占主导地位。
