在微波晶体管的高频表征中，人们常用小信号模型以相对简单的方程来参数化复杂的行为。小信号模型最好设计成其模型参数代表晶体管中某种物理量，这是迈向建立大信号模型的关键一步。它可以为优化测试结构版图、利用等效电路对完整结构进行仿真，以及研究器件参数对给定去嵌入流程的敏感性提供重要信息。用集总元件电路模型来描述双极晶体管这类物理结构存在固有的局限，但这类小信号模型在很宽的频率范围内描述晶体管行为却极为有效。同时，许多模型参数可以直接、明确地与物理量相关联，这使得表征/分析与晶体管的设计/制造之间能够形成有意义的反馈。该技术中的一个关键问题是建立物理上可接受的小信号 HBT 模型与精确的参数提取方法，它们对于设计低噪声放大器等线性射频 IC 至关重要。此外，由于在工艺集成的开发周期中，用于优化射频器件性能的器件特性数据可以通过提取小信号模型参数来获得，因此小信号建模正变得越来越重要。由于 HBT 器件的基本工作机制与 BJT 非常相似，小信号建模可以在 BJT 小信号模型的基础上考虑异质结的影响来完成。由于模型参数数量增加，其参数提取方法比 BJT 更为复杂。

本章将介绍 HBT 的小信号建模与参数提取技术，并以一只 InP HBT 器件为例加以说明。参数提取流程包括焊盘（pad）电容、外部电感、外部电阻以及本征元件的提取。

5.1 小信号电路模型

两种众所周知的基本双极晶体管模型是 T 型模型与 π 型模型；需要指出的是，T 型与 π 型拓扑都是人为构造的晶体管模型，只要模型参数的频率依赖性得到正确建模，它们可以做到完全等效。本节将对 T 型拓扑与电路拓扑进行直接比较。

5.1.1 焊盘结构

对毫米波电路与系统日益增长的需求，带来了直接在晶圆上（即在芯片级）测量元件的需要，以避开与封装、连接器及电缆相关的测量不确定性。对器件的接入通常通过共面波导（CPW）探针实现。商用探针可覆盖很宽的频率范围，有单针尖与多针尖两种配置可供选用。通过在直至探针针尖的整个路径上保持传输线阻抗，并采用接地—信号—接地（GSG）CPW 引出（见图 5.1），射频信号能够以最小的衰减和出色的阻抗控制被传送到晶圆上。在较低频率下可以采用更宽的探针间距（探针接触点中心到中心的间距）与单接地连接，但性能会有所下降。具有灵活信号和/或接地接触的可变间距配置对网络分析仪测量并无用处，因为校准要求过渡行为具有可重复性。

图 5.1 GSG 共面探针

在在片测量中，需要用于探针接触的 GSG CPW 焊盘结构。图 5.2a 给出了典型的焊盘图形，它由一条信号线与两条接地线组成；相应的等效电路模型如图 5.2b 所示，其中 Lb、Lc 与 Le 分别表示基极、集电极与发射极器件连接线的电感；Cpb、Cpc 与 Cpbc 分别表示基极焊盘电容、集电极焊盘电容以及基极与集电极之间的隔离电容；Rbx 为外部基极电阻；Rc 与 Re 为集电极与发射极电阻。

完整器件模型的 Y 矩阵可写为

\[Y = Y_{pad} + (Z_{RL} + Z_D)^{-1}\](5.1)

其中 ZD 为本征部分的阻抗参数，Ypad 表示焊盘电容部分：

\[Y_{pad} = \begin{bmatrix} j\omega(C_{pb} + C_{pbc}) & -j\omega C_{pbc} \\ -j\omega C_{pbc} & j\omega(C_{pc} + C_{pbc}) \end{bmatrix}\](5.2)

ZRL 表示寄生电阻与电感部分：

\[Z_{RL} = \begin{bmatrix} R_{bx} + R_e + j\omega(L_b + L_e) & R_e + j\omega L_e \\ R_e + j\omega L_e & R_c + R_e + j\omega(L_c + L_e) \end{bmatrix}\](5.3)

5.1.2 T 型电路模型

常规的 T 型混合小信号等效电路模型如图 5.3 所示。T 型拓扑与器件物理直接相关，便于检验所提取参数的物理合理性，其中 Cex 与 Cbc 分别为外部与本征基极—集电极电容，Cbe 为基极—发射极电容，Rbi 为本征基极电阻。

采用单极点近似，输运因子 α 可写为

\[\alpha = \frac{\alpha_o}{1 + j\omega/\omega_\alpha}\,e^{-j\omega\tau_T}\](5.4)

其中 αo 表示低频下的本征电流增益，ωα 为 3 dB 滚降频率，τT 为渡越时间延迟。

需要注意的是，本模型中忽略了外部基极—集电极电阻 Rex 与本征基极—集电极电阻 Rbc，这是因为 Rex 与 Rbc 的阻值很大，只要我们只关心正向工作，它们对频率响应的影响并不大。

图 5.3 中虚线框内的 Y 矩阵可表示为

\[Y_{11} = Y_{BC} + (1-\alpha)Y_{BE}\](5.5)
\[Y_{12} = -Y_{BC}\](5.6)
\[Y_{21} = \alpha Y_{BE} - Y_{BC}\](5.7)
\[Y_{22} = Y_{BC}\](5.8)

在串联接入本征基极电阻 Rbi 之后，有

\[Y'_{11} = \frac{Y_{11}}{1 + R_{bi}Y_{11}}\](5.9)
\[Y'_{12} = \frac{Y_{12}}{1 + R_{bi}Y_{11}}\](5.10)
\[Y'_{21} = \frac{Y_{21}}{1 + R_{bi}Y_{11}}\](5.11)
\[Y'_{22} = \frac{Y_{22}}{1 + R_{bi}Y_{11}}\](5.12)

在并联接入电容 Cex 之后，可得到整个本征网络的 Y 矩阵：

\[Y_{11} = \frac{Y_{EX} + Y_{BC} + (1-\alpha)Y_{BE}}{A}\](5.13)
\[Y_{21} = \frac{-Y_{EX} + (-Y_{BC} + \alpha Y_{BE})}{A}\](5.14)
\[Y_{12} = \frac{-Y_{EX} + (-Y_{BC})}{A}\](5.15)
\[Y_{22} = \frac{Y_{EX} + Y_{BC}(1 + Y_{BE}R_{bi})}{A}\](5.16)

其中

\[A = 1 + R_{bi}[Y_{BC} + (1-\alpha)Y_{BE}],\quad Y_{BE} = \frac{1}{R_{be}} + j\omega C_{be},\quad Y_{BC} = j\omega C_{bc},\quad Y_{EX} = j\omega C_{ex}\]

整个小信号等效电路的开路 Z 参数可表示为 [1]：

\[Z_{11} = \frac{(1-\alpha)(Z_{BC} + Z_{EX})R_{bi}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{BE} + Z_E + Z_B\](5.17)
\[Z_{12} = \frac{(1-\alpha)Z_{BC}R_{bi}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{BE} + Z_E\](5.18)
\[Z_{21} = \frac{-\alpha Z_{EX} + (1-\alpha)R_{bi}Z_{BC}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{BE} + Z_E\](5.19)
\[Z_{22} = \frac{(1-\alpha)Z_{BC}(Z_{EX} + R_{bi})}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{BE} + Z_E + Z_C\](5.20)

其中

\[Z_B = R_{bx} + j\omega L_b,\quad Z_C = R_c + j\omega L_c,\quad Z_E = R_e + j\omega L_e,\quad Z_{BC} = \frac{1}{j\omega C_{bc}},\quad Z_{EX} = \frac{1}{j\omega C_{ex}},\quad Z_{BE} = \frac{R_{BE}}{1 + j\omega R_{BE}C_{BE}}\]

5.1.3 π 型电路模型

实际上，混合 T 型小信号等效电路模型比 π 型电路模型更为常用。T 型模型之所以具有吸引力，是因为所有模型参数都可以直接与器件物理相联系，并且该模型在直至毫米波频率都能很好地拟合 S 参数数据。已有少数论文采用混合 π 型拓扑来研究 HBT 器件的小信号性能。由于可追溯到硅双极晶体管发展的历史原因，大多数双极电路设计者使用 Gummel–Poon 模型。该模型是大多数电路仿真器（如 SPICE）中可用的标准大信号双极模型。因此，对于需要大信号建模的设计（如振荡器、功率放大器与混频器），设计者必须使用 Gummel–Poon 模型。遗憾的是，Gummel–Poon 模型在小信号条件下退化为混合 π 型拓扑。因此，保持与标准 SPICE Gummel–Poon 模型的向后兼容性是很有吸引力的，这就要求紧凑型大信号模型以 π 型拓扑来表述。

图 5.4 给出了本征 HBT π 型模型：(i) gm 模式与 (ii) β 模式。gm 与 β 之间的关系为 β = gmrπ，且 gm = gmoexp(−jωτπ)。可以看出，HBT π 型模型与常规的 FET 小信号等效电路模型相似。其输入阻抗为 Zπ = Rπ + jωCπ，反馈网络由 Rμ 与 Cμ 构成。

图 5.3 中虚线框内的 Y 矩阵可表示为

\[Y_{11} = \frac{1}{r_\pi} + j\omega(C_\pi + C_\mu)\](5.21)
\[Y_{12} = -j\omega C_\mu\](5.22)
\[Y_{21} = g_{mo}e^{-j\omega\tau_\pi} - j\omega C_\mu\](5.23)
\[Y_{22} = \frac{1}{r_o} + j\omega C_\mu\](5.24)

其中 gmo 为直流跨导，τπ 为时间延迟。

在加入 Rbi 与 Cex 之后，可得到整个本征网络的 Y 矩阵：

\[Y_{11} = \frac{1 + j\omega r_\pi(C_\pi + C_\mu)}{r_\pi + R_{bi} + j\omega R_{bi}r_\pi(C_\pi + C_\mu)} + j\omega C_{ex}\](5.25)
\[Y_{12} = \frac{-j\omega r_\pi C_\mu}{r_\pi + R_{bi} + j\omega R_{bi}r_\pi(C_\pi + C_\mu)} - j\omega C_{ex}\](5.26)
\[Y_{21} = \frac{g_m r_\pi e^{-j\omega\tau_\pi} - j\omega r_\pi C_\mu}{r_\pi + R_{bi} + j\omega R_{bi}r_\pi(C_\pi + C_\mu)} - j\omega C_{ex}\](5.27)
\[Y_{22} = \frac{r_\pi r_o + j\omega r_\pi C_\mu}{r_\pi + R_{bi} + j\omega R_{bi}r_\pi(C_\pi + C_\mu)} + j\omega C_{ex}\](5.28)

由图 5.3 与图 5.4 可以看出，外部等效电路元件 Cex 与 Rbi 在两种拓扑中是相同的，因此它们具有相同的值。其余的本征参数可以相互转换 [2–7]：

\[g_{mo} = \frac{\alpha_o}{R_{be}}\frac{\sqrt{1 + (\omega R_{be}C_{be})^{2}}}{1 + (\omega/\omega_\alpha)^{2}}\](5.29)
\[\tau_\pi = \tau_T + \frac{1}{\omega}\left[\tan^{-1}\!\left(\frac{\omega}{\omega_\alpha}\right) - \tan^{-1}(\omega R_{be}C_{be})\right]\](5.30)
\[C_\pi = C_{be} + g_{mo}\frac{\sin(\omega\tau_\pi)}{\omega}\](5.31)
\[R_\pi = \frac{R_{be}}{1 - g_{mo}R_{be}\cos(\omega\tau_\pi)}\](5.32)

由此可见，两种电路拓扑之间存在一一对应关系。然而，π 模型的参数具有频率依赖性，这一点在高频下变得显著。

5.1.4 单向功率增益

1954 年，Mason 希望找到一个用于比较晶体管的品质因数，这使他发现线性二端口器件的单向功率增益是一个不变量品质因数。Mason 不变量（或称 U）是唯一在无损、互易嵌入下保持不变的器件特性。换言之，U 可用作品质因数来比较任何三端有源器件。例如，生产晶体管的工厂可以计算其所生产晶体管的 U，并将其质量与市场上的其他晶体管进行比较。此外，U 还可用作有源性的指示器：若 U 大于 1，则该二端口器件是有源的；否则该器件是无源的。单向功率增益 U（也称为 Mason 增益 U）之所以可用作品质因数，是因为它是理想网络匹配情形下的结果。量 U 可辨识为图 5.5 所示单向结构的资用功率增益。给定线性二端口的单向化，是将该器件嵌入如图 5.5 所示的嵌入网络之中的过程，使得嵌入后的器件不存在从输出端口到输入端口的反向信号传输，即 Z12 = 0，其中 Z 为变换后器件（即器件与嵌入网络的组合）的开路阻抗矩阵，定义于嵌入网络的外部端口。通常，量 U 已被用于预测化合物 FET 与双极晶体管的高频性能。

Mason 增益 U 的一般表达式被推导出来，并以网络的线性二端口 H 参数表示为 [8–10]：

\[U = \frac{|H_{21} + H_{12}|^{2}}{4\,\mathrm{Re}(H_{11})\,\mathrm{Re}(H_{22}) - \mathrm{Im}(H_{12})\,\mathrm{Im}(H_{21})}\](5.33)

当以二端口的阻抗参数表示时，U 的形式保持不变：

\[U = \frac{|Z_{21} - Z_{12}|^{2}}{4\,\mathrm{Re}(Z_{11})\,\mathrm{Re}(Z_{22}) - \mathrm{Re}(Z_{12})\,\mathrm{Re}(Z_{21})}\](5.34)

当以二端口的导纳参数表示时，U 的形式保持不变：

\[U = \frac{|Y_{21} - Y_{12}|^{2}}{4\,\mathrm{Re}(Y_{11})\,\mathrm{Re}(Y_{22}) - \mathrm{Re}(Y_{12})\,\mathrm{Re}(Y_{21})}\](5.35)

用散射参数矩阵 S 表示的 U 的表达式，可通过将恒等式代入 Z 矩阵得到：

\[U = \frac{\left|\dfrac{S_{21}}{S_{12}} - 1\right|^{2}}{2k\left|\dfrac{S_{21}}{S_{12}}\right| - 2\,\mathrm{Re}\!\left(\dfrac{S_{21}}{S_{12}}\right)}\](5.36)
图 5.5 Mason 增益的条件（嵌入线性无损互易四端口之内）

其中 k 为稳定因子，可表示为

\[k = \frac{1 - |S_{11}|^{2} - |S_{22}|^{2} + |\Delta|^{2}}{2|S_{12}S_{21}|}\](5.37)

其中

\[\Delta = S_{11}S_{22} - S_{12}S_{21}\]

需要注意的是，k > 1 与 Δ < 1 是无条件稳定的两个充分必要条件。

5.1.5 fT 与 fmax

晶体管有两个最重要的品质因数：一个是截止频率 fT，另一个是最高振荡频率 fmax。截止频率 fT 定义为器件具有单位电流增益时的频率；最大资用增益（MAG）为 1 时所对应的频率则标志着最高工作频率 fmax。

输出端口短路时的正向电流增益 h21 由下式给出

\[h_{21} = \frac{Y_{21}}{Y_{11}}\](5.38)

忽略所有寄生参数，电流增益 h21 可重写为

\[h_{21} = \frac{Y_{21}}{Y_{11}} \approx \frac{g_{mo}}{2\pi f(C_\pi + C_\mu + C_{ex})}\](5.39)

fT 定义为 h21 = 1 时对应的点；因此，fT 为

\[f_T = \frac{g_{mo}}{2\pi(C_\pi + C_\mu + C_{ex})}\](5.40)

如果晶体管是无条件稳定的（即 k > 1），则 MAG 可表示为如下形式 [11]：

\[G_{a,\max} = \left|\frac{S_{21}}{S_{12}}\right|\left(k - \sqrt{k^{2} - 1}\right)\](5.41)

如果器件只是条件稳定的，则 MAG 不能给出有意义的结果，因为当 k < 1 时源端与负载端无法同时实现共轭匹配。在这种情况下，一个有用的品质因数是最大稳定增益，它定义为 k = 1 时的 MAG：

\[G_{MSG} = G_{a,\max}|_{k=1} = \left|\frac{S_{21}}{S_{12}}\right|\](5.42)

最大稳定增益易于计算，为计算各种器件在稳定工作条件下的增益提供了便捷的途径。

fmax 定义为 MAG 为 1 时对应的点；因此，fmax 由下式给出 [12, 13]：

\[f_{\max} = \frac{f_T}{8\pi R_{bi}C_{bc}}\](5.43)

5.3 PAD 电容的提取方法

三个电容元件 Cpb、Cpc 与 Cpbc 用于建模测量探针接触的电容效应。焊盘电容最常用的提取方法有两种：一种是开路测试结构法，另一种是夹断法。其详细步骤将在下述各小节中讨论。

5.3.1 开路测试结构法

焊盘电容通过测量仅由焊盘构成的开路结构来确定 [16]。开路测试结构的测量结果被建模为一个电容 π 网络。图 5.7 给出了开路测试结构的版图及其对应的等效电路模型。该模型之所以如此简洁，直接得益于半绝缘 GaAs 或 InP 衬底以及直至半绝缘衬底的良好器件隔离。相比之下，硅器件的焊盘寄生修正要复杂得多，因为对导电衬底建模需要若干个额外的元件。

图 5.7 开路测试结构 (a) 与等效电路模型 (b)

开路测试结构的 Y 参数可表示如下：

\[\mathrm{Im}\,Y_{11} = j\omega\left(C_{pb} + C_{pbc}\right)\](5.44)
\[\mathrm{Im}\,Y_{12} = \mathrm{Im}\,Y_{21} = -j\omega C_{pbc}\](5.45)
\[\mathrm{Im}\,Y_{22} = j\omega\left(C_{pc} + C_{pbc}\right)\](5.46)

由 (5.44) 至 (5.46) 可直接得到焊盘电容 Cpb、Cpc 与 Cpbc：

\[C_{pb} = \frac{1}{\omega}\,\mathrm{Im}\left(Y_{11} + Y_{12}\right)\](5.47)
\[C_{pc} = \frac{1}{\omega}\,\mathrm{Im}\left(Y_{22} + Y_{12}\right)\](5.48)
\[C_{pbc} = -\frac{1}{\omega}\,\mathrm{Im}\,Y_{12} = -\frac{1}{\omega}\,\mathrm{Im}\,Y_{21}\](5.49)

根据 Y 参数与 S 参数之间的关系，

\[Y_{11} = Y_{o}\,\frac{\left(1 - S_{11}\right)\left(1 + S_{22}\right) + S_{12}S_{21}}{\left(1 + S_{11}\right)\left(1 + S_{22}\right) - S_{12}S_{21}}\](5.50)
\[Y_{12} = Y_{o}\,\frac{-2S_{12}}{\left(1 + S_{11}\right)\left(1 + S_{22}\right) - S_{12}S_{21}}\](5.51)
\[Y_{21} = Y_{o}\,\frac{-2S_{21}}{\left(1 + S_{11}\right)\left(1 + S_{22}\right) - S_{12}S_{21}}\](5.52)
\[Y_{22} = Y_{o}\,\frac{\left(1 + S_{11}\right)\left(1 - S_{22}\right) + S_{12}S_{21}}{\left(1 + S_{11}\right)\left(1 + S_{22}\right) - S_{12}S_{21}}\](5.53)
图 5.8 焊盘电容的频率依赖性

5.3.2 夹断法

对于完整的小信号模型，与在片测量相匹配的共面馈电结构的焊盘电容同样必须加以考虑。焊盘电容可以用开路测试结构法提取。然而，该方法要求针对晶圆上每一种器件尺寸制作专门的测试结构，并且必须忽略晶圆上的不均匀性。另一种被广泛使用的方法是夹断法，用于提取寄生的基极与集电极电容 Cpb 与 Cpc [15, 17–21]。图 5.10 给出了低频、夹断偏置条件下 HBT 的小信号等效电路模型。Cpb、Cpc 与 Cpbc 是与偏置无关的元件，而 Cbe 与 Cbc 则是与偏置相关的元件。

在截止偏置工作状态下，图 5.10 中的各电容可表示如下：

\[C_{pb} + C_{be} = \frac{1}{\omega}\,\mathrm{Im}\left(Y_{11} + Y_{12}\right)\](5.54)
\[C_{pc} = \frac{1}{\omega}\,\mathrm{Im}\left(Y_{22} + Y_{12}\right)\](5.55)

其中 Cjbeo 是零偏基极—发射极电容，MBE 是基极—发射极结的梯度系数，Vjbe 是基极—发射极内建电压。

Cpbc 的提取可以通过在不同反向基极—发射极电压下将 Cbe 与 Cpbc 之和对 (5.54) 进行拟合来完成，也可以采用迭代法：尝试不同的 Cjbeo、MBE 与 Vjbe 取值，直到 Cpb + Cbe 对 (1 − VBE/Vjbe)MBE 的曲线成为一条直线为止。图 5.11 给出了 Cpb + Cbe(Vbe) 随 Vbe 变化的典型曲线。

基极—集电极电容 Cbc 可描述为

\[C_{bc} = \frac{C_{jbco}}{\left(1 - \dfrac{V_{BC}}{V_{jbc}}\right)^{M_{BC}}}\](5.58)

其中 Cjbco 是零偏基极—集电极电容，MBC 是基极—集电极结的梯度系数，Vjbc 是基极—集电极内建电压。

实际上，在关态电容测量中，很难把焊盘电容与器件内部电容分离开来。主要问题在于被测电容的数值很大，而焊盘电容只是叠加在 pn 结电容之上的一个很小的偏移量。因此，其他参数的微小变化都会给这些电容带来很大的相对误差。

5.5 外部电阻的提取方法

与外部电容和电感相比，外部电阻更为复杂，也是一个关键问题。外部电阻显著影响直流 I–V 特性与射频性能。Z 参数法、冷 HBT 法与开集电极法是确定三个外部电阻 Rbx、Rc 与 Re 最常用的方法。

5.5.1 Z 参数法

在低频范围内，共基极电流增益 α 趋于 1；因此，在集电极电流较大（此时中性基区复合是主要的复合机制）的条件下，Rbe + Re 可由 Z12 的实部得到（见式 (5.18)）。Rbe + Re 可表示如下 [24]：

\[R_{be} + R_{e} = \mathrm{Re}\,Z_{12}\](5.68)

其中 Rbe 是基极—发射极结的动态电阻，其表达式如下：

\[R_{be} = \frac{\eta kT}{qI_{E}}\](5.69)

Re(Z12) 对 1/IE 作图所得直线的截距即为 Re 的数值。如图 5.19 所示，在极低的频率下，实测 Z12 的实部对 1/IE 呈现线性依赖，Re 可由截距得到。

需要注意的是，Z 参数法只适用于确定 Re，Rbx 与 Rc 无法同时获得。

5.5.2 冷 HBT 法

截止偏置条件下 HBT 的小信号等效电路模型如图 5.20 所示。HBT 的截止偏置条件定义为两个结均处于零偏（或反偏）的状态。在这种条件下，直流电流为零，因此共基极电流增益 α 会非常小，器件表现为一个无源元件（Z12 = Z21）。于是等效电路变得简单得多，其 Z 参数为 [25, 26]

图 5.20 截止偏置条件下 InP HBT 的小信号等效电路
\[Z_{11} - Z_{12} = \frac{Z_{EX}R_{bi}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{B}\](5.70)
\[Z_{12} = Z_{21} = \frac{Z_{BC}R_{bi}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{BE} + Z_{E}\](5.71)
\[Z_{22} - Z_{12} = \frac{Z_{BC}Z_{EX}}{Z_{BC} + Z_{EX} + R_{bi}} + Z_{C}\](5.72)

在确定了焊盘电容、串联电感与发射极电阻之后，外部基极电阻与集电极电阻可以由截止偏置条件（此时基极—集电极结与基极—发射极结均处于反向状态）下的 Z 参数确定。为了提取 Rbx 与 Rc，由 (5.70) 至 (5.72) 推导出一组用于确定基极—集电极电容 Cbc 与 Cex 的新表达式。

电容 Cbc 与 Cex 之和以及 Cex 可直接计算如下：

\[C_{bc} + C_{ex} = -\frac{1}{\omega B}\left(1 + \frac{A^{2}}{C^{2}D^{2}}\right)\](5.73)
\[C_{ex} = -\frac{(C/B)^{2}}{\omega A\left[\left(1 + \dfrac{1}{D}\right)^{2} + (C/B)^{2}\right]}\](5.74)

其中

\[A = \mathrm{Im}\left(Z_{11} - Z_{12}\right),\quad B = \mathrm{Im}\left(Z_{22} - Z_{12}\right),\quad C = \mathrm{Re}\,Z_{12},\quad D = \frac{AB + \sqrt{A^{2}B^{2} + 4ABC^{2}}}{2C^{2}}\]

外部电阻 Rbx、Rc 与本征基极电阻 Rbi 可表示为

\[R_{bx} = \mathrm{Re}\left(Z_{11} - Z_{12}\right) - \frac{R_{bi}C_{bc}}{C_{ex} + C_{bc} + j\omega R_{bi}C_{bc}C_{ex}}\](5.75)
\[R_{c} = \mathrm{Re}\left(Z_{22} - Z_{12}\right) - \frac{1}{j\omega\left(C_{ex} + C_{bc}\right) - \omega^{2}R_{bi}C_{bc}C_{ex}}\](5.76)
\[R_{bi} = -\frac{D}{\omega C_{ex}}\](5.77)

同时，基极—发射极结电容 Cbe 可提取如下：

\[C_{be} = \frac{1}{\omega\,\mathrm{Im}\!\left(Z_{12} - \dfrac{R_{bi}C_{ex}}{C_{ex} + C_{bc} + j\omega R_{bi}C_{bc}C_{ex}}\right)}\](5.78)

图 5.21 与图 5.22 给出了在 VBE = 0 V、0.2 V 且 VCE = 0 V 的不同偏置下，利用 (5.73) 与 (5.74) 提取的 Cbc + Cex 与 Cex 随频率的变化。可以观察到数值相当恒定，标准偏差很小。值得注意的是，外部基极—集电极电容 Cex 与偏置有关，它随 VBE 的增大而增大。一旦得到 Cex，Cbc 便可由 (5.73) 与 (5.74) 之差确定。还可以发现，Cbc 是基极—集电极偏置电压的弱函数。

低频、开集电极偏置条件下 Z 参数的实部可表示如下：

\[\mathrm{Re}\,Z_{11} = R_{bi} + R_{bx} + R_{e} + R_{be}\](5.79)

5.6 本征电阻的提取方法

5.6.1 直接提取法

一旦寄生元件（Cpb、Cpc、Cpbc、Lb、Lc、Le、Rbx、Rc 与 Re) 为已知，本征模型参数的提取便可按如下步骤进行 [32–37]：

  1. 测量 HBT 的 S 参数；
  2. 把 S 参数变换为导纳参数 YD，并减去焊盘电容（Cpb、Cpc 与 Cpbc）：
\[Y = Y_{D} - \begin{bmatrix} j\omega\left(C_{pb} + C_{pbc}\right) & j\omega C_{pbc} \\ j\omega C_{pbc} & j\omega\left(C_{pc} + C_{pbc}\right) \end{bmatrix}\](5.85)
  1. 把 Y 参数 YD 变换为阻抗参数 ZD，并减去串联电感（Lb、Lc 与 Le）与串联电阻（Rbx、Rc 与 Re）：
\[Z = Z_{D} - \begin{bmatrix} R_{bx} + R_{e} + j\omega\left(L_{b} + L_{e}\right) & R_{e} + j\omega L_{e} \\ R_{e} + j\omega L_{e} & R_{c} + R_{e} + j\omega\left(L_{c} + L_{e}\right) \end{bmatrix}\](5.86)
  1. 本征模型参数可按下列各式得到：
\[C_{bc} + C_{ex} = \frac{1}{\omega}\,\mathrm{Im}\!\left(\frac{1}{Z_{22} - Z_{21}}\right)\](5.87)
\[C_{ex} = -\frac{1}{\omega}\,\frac{\mathrm{Re}\!\left(\dfrac{1}{Z_{22} - Z_{21}}\right)\mathrm{Re}\!\left(\dfrac{1}{Z_{11} - Z_{12}}\right)}{\mathrm{Im}\!\left(\dfrac{1}{Z_{22} - Z_{21}}\right)}\](5.88)
\[R_{bi} = \frac{\mathrm{Im}\!\left(\dfrac{1}{Z_{22} - Z_{21}}\right)}{\omega C_{bc}\,\mathrm{Re}\!\left(\dfrac{1}{Z_{11} - Z_{12}}\right)}\](5.89)
\[\alpha_{\mathrm{o}} = \left|\alpha(\omega)\right|\Big|_{\omega\to 0} = \left|\frac{Z_{12} - Z_{21}}{Z_{22} - Z_{21}}\right|\Big|_{\omega\to 0}\](5.90)
\[\omega_{\alpha} = \frac{\omega\left|\alpha(\omega)\right|}{\sqrt{\alpha_{\mathrm{o}}^{2} - \left|\alpha(\omega)\right|^{2}}}\](5.91)
\[\tau = -\frac{1}{\omega}\,\mathrm{arctg}\!\left(\frac{\mathrm{Im}\!\left(\dfrac{Z_{12} - Z_{21}}{Z_{22} - Z_{21}}\right)}{\mathrm{Re}\!\left(\dfrac{Z_{12} - Z_{21}}{Z_{22} - Z_{21}}\right)}\right) + \frac{1}{\omega}\,\mathrm{arctg}\,\frac{\omega}{\omega_{\alpha}}\](5.92)
\[R_{BE} = \frac{1}{\mathrm{Re}\!\left(\dfrac{1}{Z_{12} - \dfrac{\left(1 - \alpha\right)C_{ex}R_{bi}}{\left(C_{bc} + C_{ex}\right) + j\omega C_{bc}C_{ex}R_{bi}}}\right)}\](5.93)
\[C_{BE} = \frac{1}{\omega}\,\mathrm{Im}\!\left(\frac{1}{Z_{12} - \dfrac{\left(1 - \alpha\right)C_{ex}R_{bi}}{\left(C_{bc} + C_{ex}\right) + j\omega C_{bc}C_{ex}R_{bi}}}\right)\](5.94)

5.6.2 混合法

以最小化实测与建模 S 参数随频率之差为目标的数值优化方法，其精度会随优化方法与初始值的不同而变化，并且可能给出非物理、非唯一的等效电路元件数值。HBT 等效电路参数提取的解析方法已有论述。遗憾的是，无论采用半解析法还是全解析法，这些方法对本征基极—发射极结电容 Cbe 的提取精度都不能令人满意，主要原因是本征基极—发射极电阻 Rbe 在整个频率范围内占主导地位，因此 Cbe 的数值对优化过程不敏感，用全解析法提取时会带来较大的统计离散。本节将介绍一种确定基极—发射极结电容 Cbe 的混合方法，它基于常规 T 型与 π 型等效电路拓扑之间的关系，使 Cbe 的精度得到了很大提高。

由 (5.29) 至 (5.32) 可以找到两种电路拓扑之间的一一对应关系。然而，π 型参数是频率相关的，这在高频时变得明显。也就是说，π 型与 T 型等效电路模型只有在低频下才是相互兼容的。低频下 π 型与 T 型等效电路模型之间的关系可写为：

\[g_{mo} = \frac{\alpha_{o}}{R_{be}}\](5.98)
\[\tau_{\pi} = \tau_{T}\](5.99)
\[C_{\pi} = C_{be} + g_{mo}\tau_{\pi}\](5.100)
\[R_{\pi} = \frac{R_{be}}{1 - g_{mo}R_{be}}\](5.101)

如前所述，混合 T 型模型中的本征基极—发射极结电容 Cbe 很难用半解析法或全解析法确定。相比之下，混合 π 型中的本征基极—发射极电容 Cπ 可以精确提取，因为本征基极—发射极电阻 Rπ 与 Cπ 处于同一数量级。因此，Cbe 可由 (5.98) 至 (5.101) 得到。由 (5.99) 可知，低频下渡越时间 τT 与 τπ 相等。然而，采用解析提取法时，τT 的精度优于 τπ，在低频尤其如此。为了高精度地得到 Cbe，必须用 τT 代替 τπ。因此，Cbe 的公式可写为

\[C_{be} = C_{\pi} - g_{mo}\tau_{T}\](5.102)

或

\[C_{be} = C_{\pi} - \frac{\alpha_{o}}{R_{be}}\tau_{T}\](5.103)

其中

\[C_{\pi} = \frac{\mathrm{Im}\left(Y_{11} + Y_{12}\right)}{\omega}\](5.104)
\[g_{mo} = Y_{21} - Y_{12}\](5.105)
\[\alpha_{o} = \alpha(\omega)\Big|_{\omega\to 0} = \frac{Y_{21} - Y_{12}}{Y_{11} + Y_{21}}\Bigg|_{\omega\to 0}\](5.106)
\[\omega_{\alpha} = \frac{\omega\left|\alpha(\omega)\right|}{\sqrt{\alpha_{o}^{2} - \left|\alpha(\omega)\right|^{2}}}\](5.107)
\[\tau_{T} = -\frac{1}{\omega}\,\mathrm{arctg}\!\left(\frac{\mathrm{Im}\!\left(\dfrac{Y_{21} - Y_{12}}{Y_{11} + Y_{21}}\right)}{\mathrm{Re}\!\left(\dfrac{Y_{21} - Y_{12}}{Y_{11} + Y_{21}}\right)}\right) + \frac{1}{\omega}\,\mathrm{arctg}\,\frac{\omega}{\omega_{\alpha}}\](5.108)

其中 Yij（i, j = 1, 2）表示图 5.3 与图 5.4 中虚线框的 Y 参数。

图 5.49 给出了 τT 与 τπ 的提取结果。显然，τT 的精度远优于 τπ。gmo 与 αo/Rbe 的比较如图 5.50 所示，二者在低频下几乎相等。图 5.51 给出了基于 T 型电路拓扑、用直接提取法得到的 Cbe。可以发现，Cbe 的确定精度不足以提取非线性电容模型的参数。采用混合提取法得到的相应结果如图 5.52 所示，Cbe 的精度得到了显著改善。图 5.53 给出了不同偏置条件 Vbe 下提取的 Cbe，并用著名的耗尽电容公式对其建模。在截止条件下，Cbe 的数值很容易从截止模式 S 参数测量中提取。从图 5.53 可以看出，提取的 Cbe 与建模数据吻合良好。电容模型参数为：Cjbeo = 48 fF、mjbe = 0.42、Vjbe = 0.684 V。

5.7 半解析法

在所有外部元件都得到之后，本征元件可以直接确定。然而，有时只有器件的 S 参数可用，难以按照前述方法提取所有外部元件。在这种情况下，半解析法非常有用 [38]，本征元件被表示为外部元件的函数。假设由集总元件构成的等效电路在整个测量频率范围内有效，则以本征元件的方差作为优化准则，通过迭代确定外部元件。更详细的步骤如下：首先，用开集电极法确定串联电感与电阻，即 Lb、Lc、Le、Rbx、Rc 与 Re。在去嵌入 Cpc、Rc 与 Lc 的影响之后，由 Cpb、Lb、Le、Rbx 与 Re 扩展的本征部分（如图 5.54 所示）的开路 Z 参数可表示如下：

图 5.54 由 Cpb、Lb、Le、Rbx 与 Re 扩展的本征部分
\[Z_{11} = \frac{Z_{11}^{I}}{1 + j\omega C_{pb}Z_{11}^{I}}\](5.109)
\[Z_{12} = \frac{Z_{12}^{I}}{1 + j\omega C_{pb}Z_{11}^{I}}\](5.110)
\[Z_{21} = \frac{Z_{21}^{I}}{1 + j\omega C_{pb}Z_{11}^{I}}\](5.111)
\[Z_{22} = Z_{22}^{I} + \frac{j\omega C_{pb}\Delta Z^{I}}{1 + j\omega C_{pb}Z_{11}^{I}}\](5.112)

其中

\[Z_{11}^{I} = \frac{\left(C_{bcp} + C_{exp}\right)R_{bi}}{C_{bcp} + C_{exp} + j\omega R_{bi}C_{bcp}C_{exp}} + \frac{1}{j\omega C_{bep}} + R_{e} + R_{bx} + j\omega\left(L_{b} + L_{e}\right)\](5.113)
\[Z_{12}^{I} = \frac{R_{bi}C_{exp}}{C_{bcp} + C_{exp} + j\omega R_{bi}C_{bcp}C_{exp}} + \frac{1}{j\omega C_{bep}} + R_{e} + j\omega L_{e}\](5.114)
\[Z_{21}^{I} = Z_{12}^{I}\](5.115)
\[Z_{22}^{I} = \frac{\dfrac{C_{exp}}{R_{bi}} + \dfrac{1}{j\omega}}{C_{bcp} + C_{exp} + j\omega R_{bi}C_{bcp}C_{exp}} + \frac{1}{j\omega C_{bep}} + R_{e} + j\omega L_{e}\](5.116)
\[\Delta Z^{I} = Z_{11}^{I}Z_{22}^{I} - Z_{12}^{I}Z_{21}^{I}\](5.117)

由于 Cbcp + Cexp 与 Cpb + Cbep 可以由低频 Y 参数得到，只剩三个未知参数待定。经过简单计算并忽略二阶小量后，得到下列方程：

\[\mathrm{Re}\left(Z_{11}\right) = \frac{\left(R_{bx} + R_{e}\right)C_{bep}}{C_{2}} + \frac{R_{bi}C_{bep}^{2}}{C_{2}^{2}}\](5.118)
\[\mathrm{Re}\left(Z_{11} - Z_{12}\right) = \frac{R_{bi}C_{bcp}C_{bep} + R_{bx}C_{1}C_{bep}}{C_{1}C_{2}}\](5.119)
\[\mathrm{Im}\left(\frac{Z_{11}}{Z_{22} - Z_{12}}\right) = \frac{R_{bi}\left(C_{1}C_{bep}^{2} + C_{1}C_{bep}C_{bcp} - C_{2}C_{bcp}^{2}\right)}{C_{2}^{2}} + \frac{\left(R_{bx} + R_{e}\right)\left[C_{1}C_{bep}\left(C_{1} + C_{bep}\right) - C_{1}^{2}C_{2}\right]}{C_{2}^{2}}\](5.120)

把 (5.118) 与 (5.119) 代入 (5.120)，可以得到关于 Cbep 的多项式方程：

\[aC_{bep}^{3} + bC_{bep}^{2} + cC_{bep} + d = 0\](5.121)

其中

\[a = -\frac{C_{1}}{C_{2}}\left(R_{bx} + R_{e}\right)^{2}\]
\[b = C_{1}\mathrm{Re}\left(Z_{11}\right)\left(R_{bx} + R_{e}\right) - C_{2}\left(R_{bx} + R_{e}\right)^{2} - C_{1}\left(R_{bx} + R_{e}\right)m\]
\[c = C_{1}C_{2}\mathrm{Re}\left(Z_{11}\right)m - C_{2}\left(R_{bx} + R_{e}\right)n + 2C_{1}C_{2}\left(R_{bx} + R_{e}\right)\mathrm{Re}\left(Z_{11}^{I} - Z_{12}^{I}\right)\]
\[d = C_{2}^{2}\mathrm{Re}\left(Z_{11}\right)n - C_{2}\left[C_{1}\mathrm{Re}\left(Z_{11}^{I} - Z_{12}^{I}\right)\right]^{2}\]
\[m = \left(R_{bx} + R_{e}\right)\frac{C_{1}}{C_{2}} - \left(R_{bx} + R_{e}\right) - R_{bx}\frac{C_{1}}{C_{2}}\]
\[n = C_{1}\mathrm{Re}\left(Z_{11}\right) + \mathrm{Re}\left(Z_{11}^{I} - Z_{12}^{I}\right)\frac{C_{1}^{2}}{C_{2}} - \left(R_{bx} + R_{e}\right)\frac{C_{1}^{2}}{C_{2}} - \mathrm{Im}\left(\frac{Z_{11}^{I}}{Z_{22}^{I} - Z_{12}^{I}}\right)\]
\[C_{1} = C_{bcp} + C_{exp}, \quad C_{2} = C_{pb} + C_{bep}\]

一般而言，Cbe 会有三个解，其中两个是非物理的（复数或大于 C2）。物理解是实数解中较小的那个。随后，把 Cbep 的数值代入 (5.118) 与 (5.119)，所有未知参数便都得以确定。

此外，提取得到的寄生元件可以作为优化过程的初始猜测值，用解析法确定的本征元件被表示为寄生元件的函数。迭代过程的流程图如图 5.55 所示。
